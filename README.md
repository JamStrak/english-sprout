# 英语小芽

适合 4—7 岁中国孩子和家长一起使用的英语练习小工具。每天一个生活短句，结合听辨、开口、生活动作和按表现调整的间隔复习。v1.4.0 将手机界面改为一次聚焦一件事：到期复习优先，完成后再引导下一项。

## 使用

在线入口：**https://jamstrak.github.io/english-sprout/**

- 手机：用 Safari / Chrome / Edge 打开网址，可添加到主屏幕。
- 自动更新（v1.4.1）：打开、回到前台或恢复联网时检查新版，下载完整后在空闲时自动切换，无需进入家长页确认。练习、录音、奖励展示、头像编辑、未完成设置和离线下载会暂缓切换。已经打开的旧版页面需先下载本次更新并重新打开，接入后不再需要手动确认。
- 离线：打开「家长」→「离线与安装」→「保存全部离线声音」。第一次需要联网，完成后可断网练习。浏览器可能清理缓存，需要时重新保存。
- 角色声音：Aiden、Ryan、Pip 泡泡猫各有完整 120 句。首页或练习点「换伙伴 / 语速」，在面板里直接点角色名字切换并试听，没有下拉菜单。「家长」→「声音与语速」也能设置，并保留「配音对照试听」；其他三位候选仅保留四句样音，暂不加入课程。
- 一键语速：同一声音面板提供 0.75×、0.9×、1×、1.15× 四档，播放中直接调整，不重播、不重新下载；保持音调并记住选择。录音回放和中文帮助仍为 1×，临时慢听为 0.8×。
- 播放加速：自动提前准备当前和邻近短句，优先当前伙伴的声音，重播复用已加载内容。加载时连续点按不会反复重启；后台缓存不再挡住播放。第一次打开未缓存句子仍取决于网络。
- 电脑本地：双击 **启动英语小芽.vbs**。窗口会自动打开，不需输入命令。
- 跨设备：记录分别保存在每台设备的浏览器里；通过「家长」→「进度备份」导出 / 导入 JSON 备份转移，当前没有账户或自动同步。导入替换本机记录，不合并。

## 已实现的练习

1. 内置 120 个原创生活短句、12 个情境主题与逐句情境配图；Aiden / Ryan / Pip 三套英文示范点名字即切换并试听，共 360 段英文和 11 段手动中文帮助。
2. 每天顺序学习 1 句；漏学不跳过。复习默认最多 5 句，家长可选 1–10 句。
3. 首页只突出当前要做的一件事，按「到期复习 → 今日新句 → 到期记忆小游戏 → 花园」选择主任务；没有到期项就跳过。点大图或主按钮开始，完成一类任务后重新计算下一步，不需要向下找入口。听、选图、说、回想分步展示。
4. 可选录音回听，最长 15 秒；录音仅在内存中，离开练习卡即清理，不上传、不自动评分。
5. 亲子根据实际表现选「再练一练 / 提示后会说 / 自己会说」，调整复习时间。首次学习次日复习，成功后逐步延长，困难时提前。
6. 每隔约一周做最多 3 题记忆小游戏：先看图尝试说，再听音选图。分别记录家长观察的表达与首次听辨，困难句次日再练。
7. 完成练习获得种子和水滴；小测与累计学习里程碑另送种子、肥料。三块地用按钮切换，一次照顾一块地，直接播种、浇水、施肥和收获；四种植物进入独立图鉴页。每块地只显示当前能做的一个操作，没有商店或整理背包。
8. 全部功能不调用外部付费 API；网页无广告、追踪脚本或运行时 CDN 依赖。漏一天不扣奖励，植物不会枯萎。

英文示范在本机用 Qwen3-TTS 预先制作，中文引导使用系统语音；使用时直接播放文件。默认 Aiden，三种声音共用学习进度。练习整幅情境图和播放图标是同一大按钮；新学与听辨会播放英文，复习和小测先安静回想，点图或换角色听示范就算使用提示。中文帮助只在主动点击“听玩法”时播放。4—7 岁建议家长陪伴；配图和语音辅助不识字的孩子，反馈仍由家长观察。120 句完成后继续复习；记录表示练习情况，不是发音评分或“完全掌握”认证。

手机常规页面不需要上下拖动：小书每页 6 个主题，进入主题后每页 4 句，搜索时每页 2 句；花园、图鉴、家长各项设置分别进入。点个人头像可直接选六种动物；自拍依次「选照片 → 选头套 → 可选调整小脸 → 保存」，每步只显示当前操作。照片不上传、不进入学习备份。

## 开发维护

运行时是静态 HTML / CSS / ES modules，无安装依赖。维护需 Node.js 22+、本地预览需 Python 3.11+。

```powershell
npm test
npm run build
python -m unittest discover -s tests -p "test_launcher.py"
python launcher.py --no-browser
```

浏览器自动化需 Playwright 与 Edge，业务回归见 `tests/browser.cjs`，手机单屏高度和真实坐标点击见 `tests/focus-browser.cjs`；其他开发电脑可用 `PLAYWRIGHT_MODULE` 指定 Playwright 模块路径，`TEST_URL` 可切换到正式网址。本地预览端口从 24736 开始，自动复用本工程已有实例；冲突时换空闲端口，只发布 dist，不打包开发脚本、运行日志或用户目录。不同端口属于不同浏览器存储位置，长期使用优先保持在线网址不变。

推送 main 后 GitHub Actions 运行单元测试、构建并发布 Pages。发布包只包含 dist。英文制作、核对与安装方法见语音说明；generate-audio.ps1 只维护中文引导，不会覆盖英文声线。普通使用无需安装制作工具。
