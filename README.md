# 英语小芽

适合 4—7 岁中国孩子和家长一起使用的英语练习小工具。每天一个生活短句，结合听辨、开口、生活动作和按表现调整的间隔复习。

## 使用

在线入口：**https://jamstrak.github.io/english-sprout/**

- 手机：用 Safari / Chrome / Edge 打开网址，可添加到主屏幕。
- 离线：打开「家长」→「保存全部离线声音」。第一次需要联网，完成后可断网练习。浏览器可能清理缓存，需要时重新保存。
- 电脑本地：双击 **启动英语小芽.vbs**。窗口会自动打开，不需输入命令。
- 跨设备：记录分别保存在每台设备的浏览器里；通过家长页导出 / 导入 JSON 备份转移，当前没有账户或自动同步。导入替换本机记录，不合并。

## 已实现的练习

1. 内置 120 个原创生活短句、12 个情境主题与逐句情境配图；Aiden / Ryan 两套英文示范可切换，共 240 段英文和 11 段中文引导。
2. 每天顺序学习 1 句；漏学不跳过。复习默认最多 5 句，家长可选 1–10 句。
3. 首页醒目显示今天要复习的句子与配图，一键进入复习。练习结合听音选图、跟说与真实情境动作。
4. 可选录音回听，最长 15 秒；录音仅在内存中，离开练习卡即清理，不上传、不自动评分。
5. 亲子根据实际表现选「再练一练 / 提示后会说 / 自己会说」，调整复习时间。首次学习次日复习，成功后逐步延长，困难时提前。
6. 每隔约一周做最多 3 题记忆小游戏：先看图尝试说，再听音选图。分别记录家长观察的表达与首次听辨，困难句次日再练。
7. 完成练习获得种子和水滴；小测与累计学习里程碑另送种子、肥料。三块地直接播种、浇水、施肥和收获，四种植物逐步进入图鉴。每块地只显示当前能做的一个操作，没有商店或整理背包。
8. 全部功能不调用外部付费 API；网页无广告、追踪脚本或运行时 CDN 依赖。漏一天不扣奖励，植物不会枯萎。

英文示范在本机用 Qwen3-TTS 预先制作，中文引导使用系统语音；使用时直接播放文件。默认 Aiden，可在家长页或练习中切换 Ryan，两种声音共用学习进度。4—7 岁建议家长陪伴；配图和语音辅助不识字的孩子，反馈仍由家长观察。120 句完成后继续复习；记录表示练习情况，不是发音评分或“完全掌握”认证。

## 开发维护

运行时是静态 HTML / CSS / ES modules，无安装依赖。维护需 Node.js 22+、本地预览需 Python 3.11+。

```powershell
npm test
npm run build
python -m unittest discover -s tests -p "test_launcher.py"
python launcher.py --no-browser
```

浏览器自动化需 Playwright 与 Edge，见 `tests/browser.cjs`；其他开发电脑可用 `PLAYWRIGHT_MODULE` 指定 Playwright 模块路径，`TEST_URL` 可切换到正式网址。本地预览端口从 24736 开始，自动复用本工程已有实例；冲突时换空闲端口，只发布 dist，不公开项目源码或用户目录。不同端口属于不同浏览器存储位置，长期使用优先保持在线网址不变。

推送 main 后 GitHub Actions 运行单元测试、构建并发布 Pages。发布包只包含 dist。英文制作、核对与安装方法见语音说明；generate-audio.ps1 只维护中文引导，不会覆盖英文声线。普通使用无需安装制作工具。
