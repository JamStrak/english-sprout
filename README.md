# 英语小芽

适合 4—7 岁中国孩子和家长一起使用的英语练习小工具。每天一个生活短句，结合听辨、开口、生活动作和按表现调整的间隔复习。

## 使用

在线入口（部署完成后生效）：**https://jamstrak.github.io/english-sprout/**

- 手机：用 Safari / Chrome / Edge 打开网址，可添加到主屏幕。
- 离线：打开「家长」→「保存全部离线声音」。第一次需要联网，完成后可断网练习。浏览器可能清理缓存，需要时重新保存。
- 电脑本地：双击 **启动英语小芽.vbs**。窗口会自动打开，不需输入命令。
- 跨设备：记录分别保存在每台设备的浏览器里；通过家长页导出 / 导入 JSON 备份转移，当前没有账户或自动同步。导入替换本机记录，不合并。

## 已实现的练习

1. 内置 120 个原创生活短句、12 个情境主题，以及 120 段英文示范与 8 段中文引导。
2. 每天顺序学习 1 句；漏学不跳过。复习默认最多 5 句，家长可选 3 / 5 / 8 句。
3. 先回想、再提示；结合三选一听辨、跟说与真实情境动作。
4. 可选录音回听，最长 15 秒；录音仅在内存中，离开练习卡即清理，不上传、不自动评分。
5. 亲子根据实际表现选「再练一练 / 提示后会说 / 自己会说」，调整复习时间。首次学习次日复习，成功后逐步延长，困难时提前。
6. 成长花园记录真实练习次数；无排行榜、无断签惩罚。
7. 全部功能不调用外部付费 API；网页无广告、追踪脚本或运行时 CDN 依赖。

示范音频为本地系统合成语音。4—7 岁建议家长陪伴，听辨选项可由家长读出。120 句完成后继续复习；本版本没有无限生成新课程。记录表示练习情况，不保证特定学习效果。

## 开发维护

运行时是静态 HTML / CSS / ES modules，无安装依赖。维护需 Node.js 22+、本地预览需 Python 3.11+。

```powershell
npm test
npm run build
python -m unittest discover -s tests -p "test_launcher.py"
python launcher.py --no-browser
```

浏览器自动化需 Playwright 与 Edge，见 `tests/browser.cjs`。本地预览端口从 24736 开始，自动复用本工程已有实例；冲突时换空闲端口，只发布 dist，不公开项目源码或用户目录。

推送 main 后 GitHub Actions 运行单元测试、构建并发布 Pages。发布包只包含 dist。语音维护脚本使用 Windows System.Speech 与 FFmpeg；普通使用无需这些组件。
