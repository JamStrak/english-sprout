## 内容边界

- 这批是 **新增 60 句**；现有 55 个故事对应的 53 句独立表达不计入数量，不改旧课程 ID 或学习记录。
- 一个表达一门课，一个稳定的 `daily-` 事件 ID。每句首先只制作一幅清晰关键图；不会用不同角色、物品或三张插图把同一句算成三门新课。
- 复习使用孩子已经认识的熟悉主图，直接听、回想和练习；不默认重播四格故事，也不在普通复习中突然换情境。其他情境若以后增加，只作为同课的可选延伸，不新增课数。
- 选句兼顾熟悉、自然和儿童主动表达。礼貌接受、征求加入、主动帮忙、表达个人边界等功能可以分别学习；不是只换水果名、角色名或人称来扩容。
- 定稿已把原候选第 3、5、25 条分别调整为 `Peekaboo!`、`Guess what!`、`Let's clean up.`。`I love you.` 已在旧包，不重复新增；旧接受别名 `Well done!`、`Play with me.`、`Goodbye.` 等也不另算新句。
- `easy` / `later` 仅用于产品安排与情境复杂程度，当前为 49 / 11 句，不是经过验证的年龄或能力分级。适用目标仍为 3–6 岁，不能据此宣称每个三岁孩子都应独立完成全部表达。

## 字段契约

| 字段 | 含义 |
| --- | --- |
| `number` | 本包的连续编号 1–60，不作为持久学习记录键 |
| `id` | 稳定的 `daily-` 事件 ID，英文可读 slug；接入后不得随图片返修重命名 |
| `english` | 配音与课程对应的完整英文表达；一词表达也保留完整意义 |
| `meaning` | 家长可读的简短中文意义 |
| `themeId` | 现有六主题之一：`hello`、`food`、`play`、`care`、`outside`、`bed` |
| `goalId` | 现有沟通目标之一，用于分类，不能单独代表掌握证据 |
| `title` | 中文场景名称 |
| `scene` | 单幅关键图中的说话者、对象、动作和理解线索 |
| `hint` | 孩子可听的短中文情境解释，不是读题或选择题说明 |
| `difficulty` | `easy` 或 `later`，仅作学习安排提示 |

## 给资产制作的要求

- 延用已接入小芽英语的手撕纸、雾林茶奶风格和小芽／伙伴角色参考；角色造型、比例、材质与上一包保持一致。
- 图中不放英文、中文字幕、字母、文字气泡、选择题按钮或伪装成交互按钮的装饰。教学语音和可交互控件由应用承担。
- 一幅画集中表现一个沟通意图。必须能明确谁在说话、对谁说、为什么此时会说这句话；背景和道具为这个关系服务。
- 礼物赠送与普通递交、主动帮助与请求帮助、游戏进行中的鼓励与完成后的庆祝，要用动作和物品状态区分，不能复用同一幅只改标题。
- 注意手掌与手背方向、手指数量、握持归属、肢体交叠和物体接触；尤其第 33 句击掌，不得出现手掌翻到手背或额外手指。
- 隐私与感受类画面温和清楚：上厕所场景完整穿衣、无使用中的如厕描写；疼痛不画血或伤口；害怕不靠恐吓元素；表达不喜欢或要求停止时，伙伴认真倾听。
- `Guess what!`、`I don't understand.`、`I have an idea.` 等抽象度较高的表达，使用 JSON 指定的具体活动和中文语音帮助解释，不制造靠猜图答对的任务。
- 应用接收逐张压缩、可独立加载的 WebP；原始高分辨率生成图保留在实验室。尺寸、透明背景与交付文件路径由主任务按现有图片加载器接口协调，不把整批原图放入首屏下载。
