# 小芽英语 v0.12 · B 花园经济规则

2026-10-18，用户确认“允许保留”。本版只升级 B 自由小花园，A 保持对照。目标是让贝壳用于挑选、积攒种子，让水用于分配生长；奖励依然只记录参与，不代表口语掌握。

## 数值与选择

| 行为 | 结果 |
| --- | --- |
| B 首次参与 | 2 贝壳＋5 水；首个惊喜包固定雏菊，能完成一次种植开花 |
| B 后续参与 | 自选 2 贝壳或 5 水，选定并成功保存后到账 |
| 惊喜包 | 2 贝壳；新手首包后 12 种等概率，可重复；无付费购买 |
| 指定种子 | 普通 3、蝴蝶结 6、巨型 8 贝壳 |
| 生长 | 普通及蝴蝶结 5 次、巨型 10 次，每次消耗 1 水 |

从零积攒指定蝴蝶结需要三次选贝壳，巨型需要四次；分别还要一次、两次选水才能养成。孩子可以先获得惊喜，也可以把喜欢的花留好再攒贝壳，已有水可以分给任意未开花植株。这是初始试玩数值，不声称已验证长期平衡。

## 商店与保留

- 同屏两个主要商品：惊喜包和一包可见品种的种子。整张商品卡都能点击；右上角星星为独立保留按钮，点击反馈变为勾选。
- 当前商品以本机日历日刷新。同日重开保持，购买后立即换成不同品种，不提供手动付费刷新。
- 唯一保留位免费、无到期时间。跨天、刷新、关页都保留；买走或确认更换才结束。
- 当前商品与保留位共享同一商品 ID。买走同一商品时清理保留并补货；买较早的保留商品不影响当前商品。不能重复购买同一 ID。
- 已有一颗待种种子时，先去播种；不叠加第二颗待种种子。贝壳不足不扣钱，不改变商品。
- 价格以贝壳图标、数字和填充圆点表达；语音解释选择、保留、换保留、余额不足。短屏的旧保留卡横排，保留可见的返回及继续学习按钮。

## 记录、兼容与反馈

`garden-meadow.js` 是 B 资源规则唯一实现。存储键保持 `xiaoya-english:meadow:v1`，内部 schema 升到 2，旧 schema1 完整验证后迁移。保存旧快照与新交易账本，可重新核算贝壳、水、购买、坐标和成长；不重算、清空或补发旧资源。只打开过旧 B、尚无参与的空存档仍按新手处理。

未选择的礼物可在回园时继续领取，跨标签共享 Web Lock 串行更新；重复点击不能重复领取或购买。先成功保存，再反馈到账；失败保留恢复入口。切页、弹层、后台使迟到 UI 反馈失效，但已请求的正确存储操作仍可完成。学习记录只接收参与字段，资源选择不改变复习证据。

新增 `seed-shop.js` / `economy.css`，复用既有纸艺花朵和资源，不引入图片包。13 条新静态语音使用独立 `economy-*` URL，旧声音内容及 v3 缓存路径不变；按需播放并缓存。生成工具、文本与逐文件 SHA 保存在 `scripts/generate-xiaoya-economy-speech.py` 和 `public/xiaoya/audio/economy-voice-manifest.json`。运行时无配音服务调用。

实际版本、验证范围与入口见 `PROJECT_CONTEXT.md`、`docs/XIAOYA_IMPLEMENTATION.md` 和 `docs/XIAOYA_USE.md`。
