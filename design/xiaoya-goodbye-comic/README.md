# 小芽英语 · 告别漫画试点

2026-10-16，供 `hello-goodbye`（See you later）单事件体验使用。先通过连续情境呈现含义，再邀请孩子参与表达；观看漫画本身不是听懂或会说的证据。

## 素材

- `goodbye-v2.png`：内置 image_gen 编辑后的完整原图，1448 × 1086，2,311,068 字节。
- `prompt.json`：本次实际编辑提示词与来源记录，修正挥手小熊手背上错误的掌心斑点，保留角色、场景和叙事。
- `../../public/xiaoya/stories/goodbye-v2.webp`：运行时图片，150,210 字节；仅做 WebP 格式压缩，未手工绘制或重新生成画面。

四格依次为一起玩球、背包准备离开、门口相互挥手、走到户外小路。页面每次只展示一格，英文在挥手一格播放。图片按进入故事时加载，不进入首页核心预下载包；源码原图和提示词不发布到 `dist`。

## 画面复核

修正版已逐格查看：挥手掌背不再带掌心肉垫，手腕连接自然；人物数量、背包、门的朝向与离开方向保持连贯；没有文字、字母或对话框。源图分格并非严格等高，运行时须按实际内容裁切并检查小屏，不可直接四等分露出邻格。

后续出图继续逐张检查掌心与手背、左右手、关节、肢体数量、角色一致性，以及动作是否准确表达所教含义。提示词约束不能代替出图后的视觉检查。真实儿童是否理解告别、是否愿意跟着开口仍需试玩观察。
