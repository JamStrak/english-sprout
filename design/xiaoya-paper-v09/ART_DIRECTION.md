# 小芽英语｜手撕纸花园 r001 实施卡

目标：面向 3–4 岁儿童，用温柔、易读的情境图支持听说理解；让家长看到克制、统一、有质感的美术包装。不改变课程内容和现有产品流程。

## 1. 锁定身份与画法

- **小芽 Xiaoya 是浅绿、双叶芽头精灵，不是小熊。** 双叶头顶轮廓必须在小尺寸下可认；沿用现有主角参考中的脸、比例与识别点，不自行替换物种。
- 小熊是伙伴，与小芽分工明确；同一伙伴在三幅图里保持毛色、体型和脸部设计一致，不每张换一只熊。
- 画风 **273 / `handdraw-273` / Hand-Torn Paper Collage Illustration（手撕纸拼贴）**：大块剪撕纸形、温润纤维边、少量纸层叠压；五官与动作清晰，体积主要靠色块，不靠写实光照。
- 风格参考只取纸艺媒介、边缘和简化程度；不取其人物、故事、构图或原参考配色。不指定在世作者仿作。
- 配色 **09 / `tea-milk` / 雾林茶奶**。选定配色优先于风格样图颜色。保留少量同色系自然纸纹，不增加彩虹式点缀、重噪点、厚重阴影或 3D 塑料高光。
- 不同图复用同一主角参考；身份、头身比、色彩角色、纸纹尺度保持不变。先确认这小批，再扩展资源库。

## 2. 配色与 UI tokens

以下是本轮色卡约束，不从示例截图反向估色。插画可有自然明暗过渡，关键 UI 使用确定色值。

| Token / 角色 | 色值 | 用法 |
| --- | --- | --- |
| `paper` / 背景 | `#EFEADF` | 奶纸底、留白、主按钮上的浅色图标 |
| `surface` / 面板 | `#CCD4BD` | 浅灰绿分区、安静的花园层次 |
| `ink` / 主体 | `#344B45` | 关键图标、必要文字、主按钮底 |
| `sage` / 次要 | `#749986` | 植物和辅助色块，不作关键小图标 |
| `clay` / 点缀 | `#D08D6C` | 熊伙伴与温暖装饰，控制面积 |
| `warm-red` / 警示 | `#A94948` | 少量警示；插画中的苹果也可取此色，不因此代表错误 |

对比度按上述不透明 sRGB 色值计算：

- `ink` 对 `paper` **7.82:1**，对 `surface` **6.13:1**；主按钮用 `ink` 底、`paper` 图标。
- `clay` 对 `paper` 仅 **2.27:1**，`sage` 对 `paper` 仅 **2.63:1**，不用于关键按钮或小图标。
- `surface` 对 `paper` 仅 **1.28:1**；必要的可点击边界由清晰形状或 `ink` 轮廓承担，不能只靠这点色差。
- `warm-red` 对 `paper` **4.69:1**。这些结果不覆盖透明度、纸纹叠加和真实设备显示，合成后仍需在 APP 实际尺寸检查。

教学物体的识别优先：苹果保留可辨认的固有色；小芽保留浅绿身份。若现有主角标准色与色卡有差异，作为明确的角色身份例外记录，不能偷偷改主角或扩散新色。

## 3. 首批三张语义图

统一 **7:5 单幅情境图**。一张只表达一个事件，主要角色不裁切，双手、接触点和关键道具不要互相遮挡。图中不出现英文、汉字、字母、数字、伪文字或标签；句子通过 APP 音频播放。

| 图 | 核心事件 | 必须读清 | 删掉什么 |
| --- | --- | --- | --- |
| 01 · I love you | 小芽与熊伙伴温暖拥抱 | 两者真实相拥、放松的脸、清晰手臂接触 | 多余角色、礼物、满屏爱心、抢主体的花园 |
| 02 · Thank you | 熊伙伴递一枚苹果，小芽接住并看向伙伴表达感谢 | 谁给谁、唯一的苹果、接物与回应关系 | 苹果堆、货架、文字气泡、与递物无关的动作 |
| 03 · Let's go home | 小芽背小包，与熊伙伴准备一起回家 | 伙伴关系、同向出发、可辨认的小屋作为目的地 | 分岔选择、复杂路径、多个房子、告别或逃跑语气 |

画面是语义支撑，不假装一张静态图就能无歧义表达所有抽象句意；尤其“谢谢”和“一起回家”需与原句音频共同检查。大形准确先于漂亮纹理。

## 4. 首页与花园包装：可直接落地的结构

**首页**：奶纸底；上半区放小芽陪伴贴图，下半区只突出一个“继续今天学习”的主操作，以现有流程支持的图形与音频引导呈现。主按钮用深茶底、奶纸图标，图标由代码或矢量绘制，不烘焙进插画。家长入口、小设置保持次级且与儿童主操作分开；儿童主画面不靠文字说明。

**花园**：一张低细节背景，奶纸天空、灰绿植物、少量陶色花盆；中间保留干净区域承载主角和当前学习入口。环境本身不伪装成一排按钮，也不同时摆满任务、奖励和可点对象。只让当前可操作目标有明确反馈；主角、交互控件、背景分层，便于后续替换与动效。

**包装延伸**：应用图标优先取“小芽双叶轮廓＋大脸”的简洁裁切；宣传主视觉用“小芽＋熊伙伴的一次互动”，周围留标题位置，不把品牌文字生成进图片。纸艺造型、色卡、角色身份跨图标、首页、花园和商店包装统一。

**交互底线**：每屏只给一个突出的主动作；儿童触控区建议至少 56×56 逻辑像素并保持间距，不把装饰当控件。点击反馈用形变、描边和声音协同，不仅换颜色；不堆叠闪烁、礼花、彩色边框或多个同等级强按钮。实际控件尺寸与儿童试用由 APP 任务验证。
