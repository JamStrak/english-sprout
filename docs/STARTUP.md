# 首次打开与 iPadOS 15.1 兼容

2026-10-12，v1.5.2。用户在 iPadOS 15.1 浏览器看到“检查网络／需要先联网一次”。

## 根因与复现

原 init 把课程请求、学习计划计算、渲染、试听和离线初始化包在同一个 catch 中。缺少 Object.hasOwn 或 Array.prototype.at 时，课程请求已成功、设备仍联网，首页计算却抛异常，最后被误报为网络问题。structuredClone 缺失还会导致种植失败。Safari 在 15.4 才加入这些 API 和原生 dialog，见 [WebKit 发布说明](https://webkit.org/blog/12445/new-webkit-features-in-safari-15-4/)。

隔离浏览器删除这些 API 后已复现同款提示；课程请求单次 503 也可造成启动失败，恢复联网事件还会访问未初始化状态。离线服务注册失败或预缓存头像失败本身不阻断联网首页。原始证据保存在 test-results/startup-diagnostic。能力模拟不等于实体 iPad 验收。

## 当前行为

- 构建从 public/data/curriculum.json 唯一来源生成首页内嵌的非执行 JSON，正确转义 HTML 定界符；不另维护一份课程。首页不再等待单独的课程请求。独立 JSON 保留给旧页面和核心离线缓存。
- 旧页面或源码预览无内嵌数据时，课程请求有超时和最多三次自动重试；网络恢复后自动继续。启动未完成时不响应会触发渲染的路由、存储和可见性事件，完成后读取最新路由与记录。
- 课程连接错误、界面异常分开提示和记录。可选试听或离线准备失败不覆盖可用首页。入口模块下载失败时，HTML 本身按5/10/20/40/60秒自动重开，成功后停止重试，也保留可选立即重试入口。恢复网络自动继续；同构建样式首次请求失败时，完整缓存准备好后安全重开，避免HTML/JS成功掩盖CSS缺失。
- compat.js 使用局部属性判断、末项读取及验证后 JSON 数据复制，不修改全局原型。学习 ID、记录结构、复习间隔、花园奖励规则保持。
- dialog.js 优先原生弹窗；旧浏览器提供遮罩、焦点限制、Escape、取消和关闭事件，兼容头像、声音、皮肤、确认和试听。
- 旧浏览器的高度来自可见 window.innerHeight；CSS 提供 vh 和静态混色回退，现代浏览器继续使用 dvh 和 color-mix。resize／旋转更新可见高度。

## 下载与更新边界

联网进入后可以直接学习；当前句有限预热，其他声音点播获取并缓存。无需先点“保存全部离线声音”；该入口只用于提前保存整本内容。首次完全断网且从未取得页面和音频时，浏览器无法凭空提供这些内容。

核心文件全部缓存成功、两份HTML构建标记及所有核心SHA-256均匹配之后才激活新版；模块/样式路径按构建隔离。页面周期检查与worker安装退避共同恢复下载失败，旧页面仍可继续使用。不会清理学习记录、自拍或旧声音缓存来解决启动问题；声音缓存继续v5。本轮没有重新配音。自动更新细节见docs/DESIGN.md。

## 验证入口

- npm test：包含缺失 API 后新学、复习、小测、种植及备份与正常结果一致；内嵌课程、安全序列化、超时重试与可见高度单测。
- tests/startup-browser.cjs：两种视口的新用户、旧记录、网络失败、按需真实播放、离线重载及启动错误恢复。
- tests/dialog-compat.cjs：缺少原生弹窗 API 后的实际点击、焦点及清理。
- 原 tests/browser.cjs 与 tests/update-browser.cjs 继续作为功能和自动更新回归；本轮发布版本、结果与线上证据统一记录在 PROJECT_CONTEXT.md。
