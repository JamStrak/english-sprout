## 目标

每天少量可以当场使用的英语短句，让4—7岁孩子在家长陪伴下听、理解、开口，再在间隔后主动回想。早期版本不依赖账号、付费服务、实时AI评分或云端数据库。

采用暖纸色、森林绿、种子黄、原创小兔花园插画。首页只突出当前一项任务的大图和主按钮，优先级为「到期复习 → 未完成的今日首句 → 到期记忆小游戏 → 额度内再学一句 → 花园」。完成一类任务后重新读取当前计划，再给出下一步；当天复习可能改变小测候选，不能沿用进入前的快照。没有到期项就跳过；全部完成后可再听当天一句，自由练习不改进度。未识字儿童仍由家长陪伴，抽象句意通过生活情境解释。

## 手机单屏与顺序

- 听、听音选图、开口、回想分别占一屏。主要操作始终在当前屏内；提示、录音状态和答题反馈就地显示，不把新信息追加到屏幕下方。底部导航保留自主转场，完成页可继续下一项或先休息。
- 小书先选主题，每页 6 个主题；主题内每页 4 句；全局搜索每页 2 句。用明确的上一页、下一页按钮翻页，不横向滑动找内容。
- 花园每次展示一块地，三个按钮切换地块；图鉴独立一屏。中央花田配合种子、水壶、营养三个可拖道具，保留点选后点花田。v1.6.0支持同日反复照顾、12步成长和独立跟读领水，详见GARDEN.md。
- 家长页先展示六个用途入口：宝贝昵称与练习、声音与语速、离线与安装、进度备份、学习足迹、陪伴方法。昵称在第一项直接编辑并保存，最多 16 个字符，不要求真实姓名（v1.5.3 将原“练习习惯”入口改为明确提到昵称，功能与记录不变）。安装/二维码从离线页进入，关于与隐私从陪伴方法进入；子页有明确返回按钮。家长页不是身份认证或儿童锁。
- 单屏以内容实际放得下、文字和控件没有被裁切为准，不能用隐藏溢出掩盖问题。小尺寸压缩重复说明，必要设置独立展开；不牺牲主按钮的可见与点击。

## 触摸、声音与头像

- Aiden、Ryan、Pip 泡泡猫各有完整 120 句。首页和练习用「换伙伴 / 语速」打开独立声音面板，面板内仍是带动物的名字按钮，点选即播放当前句，不使用音色下拉菜单。家长的声音子页直接展示这些选项。新句及听辨步骤直接播放英文，中文帮助仅在主动点“听玩法”时播放。
- 情境图的角色、空白和播放图标属于同一大按钮，点任意位置都能听当前句；复习中点图明确作为听提示。听辨选项的图片保持“作答”含义，不将不同答案变成播放按钮。
- 已出声后再次点击会重播；同一句同速度仍在加载时，连续点按共用正在进行的播放请求，不重新下载或排队。真实媒体事件控制载入、播放、播放结束与失败提示；正在说话的伙伴、图片和声波同步显示。退出、切声、录音与跨页状态变化会取消旧声音。
- 首页提前准备当前主任务、当天新句和少量复习，优先当前角色；短句小书准备当前页前两句，并在触碰/聚焦卡片时准备该句；练习中准备当前句与下一句。最多保留六个静默音频元素，点播复用已下载的缓冲，避免全课程自动抢占网络。回想与小测的预加载不播放、不揭示答案。浏览器可能限制预加载，第一次未缓存的请求仍受网络影响。
- Service Worker 收到网络音频流就交给播放器；完整内容的缓存写入由后台生命周期保护，不挡住播放。原两套成品保持原字节，新增 Pip 120 句。家长页可保存三套课程、中文帮助与额外样音，去重共 383 段。
- 所有按钮和链接都有短暂触点圆圈、星星与边框反馈，不增加额外提示语音；照顾键盘操作和减少动态效果设置。答题、录音、花园操作分别保留就地状态反馈。
- 六个原创动物头像可直接选用。自拍分为选照片、选动物头套、可选调整小脸大小/位置几个屏内步骤，确认保存才替换头像；选照片和裁剪滑杆不与整组选项堆在一页。头像独立保存在当前浏览器，不写进学习进度备份，不上传照片；切换预设或删除自拍可移除保存的照片。
- 复习与小测不会自动放答案。点画面或角色听到提示会同步揭晓；小测随后不能选“自己会说”，避免把刚听过当作独立回想。

## 语速与对照试听

首页和练习的声音设置面板、家长的声音子页提供 0.75× / 0.9× / 1× / 1.15× 四档大按钮；小书打开具体短句后可调。常规页面不再同时摊开三位角色与四档语速。当前课程播放流就地保调变速，不 seek、不重开请求；停播时调速不自动发声。练习声音面板里保留临时慢听 0.8×，不覆盖常规档位。中文帮助与个人录音始终 1×。语速偏好使用独立的 english-sprout-course-rate-v1，首次只迁移有效试听档位；后续两处选择独立，不修改学习记录。

家长的声音子页保留「配音对照试听」，首页不再推广未采纳候选；`?audition=1` 仍可直接打开，但不自动播放。Pip 标为完整课程角色，Pogo / Milo / Lulu 仅为四句样音，后续版本待定，不再要求选一男一女。原 Aiden / Ryan 仍可对照。动物、姓名、播放标记共用大按钮；切句重听当前角色，关闭、切后台或导航及时停止声音。对照面板在 320×568 及以上的已测视口内展示短句、四档语速、候选角色、原声对照和底部状态；压缩重复说明，不依赖中间滚动或让底栏遮住参考角色。

声音缓存 v5：从 v4 优先迁移原 251 段和 16 段已知样音，v3 补原课程缺项；不覆盖新缓存，失败可离线回退且保留旧缓存。新增 Pip 116 句不误读旧缓存。Pip 的四句样音与完整课程共用文件，离线下载去重为 383 段。配音 manifest JSON 使用 core 缓存，不进行 MP3 Range 处理。

## 练习原理

间隔复习与主动回想是设计依据，但1、3、7、14、30、60、90天是本应用可解释的调度选择，不是儿童个体的精确遗忘曲线。选择题只作为听辨练习，不能自动证明口语能力。

第一次新句按「听一听→选一选→说一说」；复习先给情境与中文意思，让孩子试着回忆，再按需给音频与文字提示。本机词句匹配后听音找图，自动记录回想与理解。未成功识别的手动继续不记通过。软件不将观看卡片、点击播放或自动语音识别分数当成掌握。

记忆小游戏每周最多三句，先延迟回想后听辨，结果分开记录，不把刚听过的模仿算作长期掌握。收集奖励来自实际尝试，不要求全部答对；花园提供1600株的自由种植画布，种子与水壶拖放，5次浇水开花；单屏突出种植与成长，独立跟读领水，不惩罚漏学。

学习资源与资料来源（2026-10-08核对）：

- [Haebig et al. 2019，Retrieval-Based Word Learning II](https://pubmed.ncbi.nlm.nih.gov/30986145/)。约五岁儿童的新词实验中，间隔提取比即时提取带来更好的延迟回忆；这是本产品采用先回想的依据，不是本课程或固定天数的效果验证。
- [The Learning Scientists：Expanding Retrieval Practice for Preschoolers](https://www.learningscientists.org/blog/2022/2/3-1)。学龄前间隔回想的研究介绍及原研究链接；支持采用轻量回想活动，不证明本应用的具体效果。
- [Carpenter et al.，The science of effective learning with spacing and retrieval practice](https://doi.org/10.1038/s44159-022-00089-1)。间隔与提取练习综述，不把综合研究效果直接移植为本产品承诺。
- [MDN getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)。录音需要安全上下文与用户许可。无麦克风或拒绝权限时可以继续口头练习。
- [GitHub Pages 文档](https://docs.github.com/en/pages/quickstart)。通过静态托管提供 HTTPS 入口，应用不需要后端算力。

## 用户数据与设备

- 课程和音频内置；录音只在内存中回听，离开练习卡或页面时关闭轨道并释放。
- localStorage 保存昵称、课程与复习日历，Cache Storage 保存离线文件；二者都可能被浏览器清理。
- 手机和电脑独立保存进度，手工导出导入迁移，不伪装成云同步。
- 头像照片只在本地缩小、裁剪及合成；原始照片不持久保存，最终头像不超过约 200 KB。进度导出不携带头像照片。
- 家长页是操作分区，不是身份认证或儿童锁。
- 不采集姓名、年龄、位置、联系人、行为分析或发音数据；不含第三方跟踪脚本。
- 普通网页访问会经过托管平台，不能宣称没有任何网络元数据。

## 自动更新（v1.7.2）

不设家长更新确认入口。HTML、JS、CSS 和 Service Worker 共同属于一次构建；JS/CSS 使用 releases/<build>/src 的独立路径，避免旧 worker 把新版 HTML 与旧样式混用。安装预缓存后校验所有核心文件的 SHA-256，而非只校验 HTML 标记；服务器返回旧文件即使状态为 200 也拒绝激活。下载失败保留完整旧版，音频缓存仍为 v5，学习记录与头像不清空。首页品牌下及练习进度旁显示当前页面实际版本，不使用 URL 参数或服务器最新版本冒充运行版本。

页面在前台联网时每 15 秒检查，发现新版或请求失败后每 5 秒重试，恢复联网、聚焦和回前台也触发检查。版本接口和 sw.js 不走旧 worker 的离线响应；检查有超时，挂起的原生更新请求复用，避免无限堆积。首次模块加载失败会按 5/10/20/40/60 秒自动重开恢复，成功后清除重试计数，不要求用户刷新。

新 worker 自身安装失败也按 5/10/20/40/60/60 秒重试，七次尝试均失败才结束安装，帮助尚没有周期检查的历史页面跨过短暂发布失败。新版 HTML/JS 已运行但首次样式请求失败时，完整同构建缓存准备好后也按安全时段自动重开，避免“版本最新但没有样式”。

同构建的样式恢复在当前历史条目中最多自动重开一次，全部样式加载成功才清除标记；永久浏览器策略拦截不形成刷新循环。历史条目只记录构建号，不包含儿童信息。

各标签页独立等待连续 1.5 秒的安全时段：练习会话、录音及授权中、播放中、奖励完成页、打开的对话框、家长编辑子页、输入焦点、离线下载、隐藏页面或保存失败时均暂缓。完成页继续展示奖励，正常点下一步或返回首页后才应用更新。新 worker 激活后，只在所有标签页确认已运行当前构建时删除旧核心缓存；尚在练习的旧标签和无法确认版本的历史标签保留旧文件，支持离线继续操作。

缓存清理还须确认发起者仍为active worker，并且没有正在安装或等待的新worker；每个异步删除前再次核对。避免旧页面的周期清理误删新版本安装中的候选缓存。

断网恢复后若完整安装的新worker仍留在waiting，页面读取其构建号，只有与新鲜版本接口目标相同才发送ACTIVATE_UPDATE兜底；不激活未完成安装的候选。页面刷新仍经过同一安全时段，不因激活兜底打断练习或录音。

已经打开的历史页面无法凭发布获得新的检查定时器；普通打开、重新聚焦或原有更新检查发现新 worker 后会进入自动切换。v1.7.1 旧缓存到 v1.7.2 的普通打开/单次刷新迁移用真实旧代码验证，不要求清缓存、修改网址或重复刷新。离线或服务器文件尚不完整时继续可用旧版，待恢复后自动重试，不能承诺断网立即取得新版。

实现参考：[ServiceWorker skipWaiting](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerGlobalScope/skipWaiting)、[Clients.claim](https://developer.mozilla.org/en-US/docs/Web/API/Clients/claim)、[registration.update](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerRegistration/update)。控制器切换影响同作用域标签，页面是否刷新由各自的空闲检查决定。

自动更新验证：v1.4.1 / `63eedd283640` 的 123 项单元、36 项功能回归、12 项真实 Service Worker 切换场景全部通过。断网升级测试同时让服务器拒绝连接；仅对页面使用 Playwright 离线开关，不能假定浏览器内部的 worker 更新请求也被切断。

## 儿童操作与成功反馈（v1.7.1）

开口步骤录音是主操作，整条按钮手机至少72px高、其他屏80px，麦克风图标29–34px；回听44px辅助按钮，领水/继续44px，避免奖励入口压过录音。短屏减少重复文字与已通过时的示范文字，保留大图与点击听音，单屏不滚动。

匹配通过三颗星依次跳出、结果卡弹跳、金色火花和短促上行铃声；听懂选图、领奖、播种、浇水、开花采用独立图案/音效。未匹配不播放通过音，错题温和耳朵提示和示范重听。录音/答题/工具点击仅中性触点圈，区分点击与成功，避免点击就像得星。庆祝不阻挡点击，不要求等待动画完成。最多一个短动效/8粒子、一个提示音/4音符，同时录音/示范/个人回听时停止音效，切后台清理；减少动态设置显示静态高亮。大花园画布只发光不缩放控件，保留拖放坐标。

src/child-feedback.js/css使用本机WebAudio合成短铃声，无额外音频网络资源；真实操作中解锁，首次开页不发声，没有添加自动女生引导。AudioContext缺失/不能解锁时仍能显示完整成功视觉，不影响学习与奖励。原配音和audio-v5保持。
