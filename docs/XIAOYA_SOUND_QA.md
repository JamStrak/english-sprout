## 使用与实际限制

普通入口双击 `启动小芽英语启蒙正式版.vbs`（v0.24.1 统一入口名称），进入「GM 内测 → 音效管理」。普通模式修改保存在当前浏览器；带 `gm=test` 的侧栏预览为内存沙盒，刷新重置。需要保留调音结果时使用普通入口。上传只读取本机文件，不上传服务器；配置不会自动发布成其他用户的默认值。

已完成候选比较、解码、音量和频谱检测、原生浏览器播放与界面检查；**未进行扬声器主观听感验收、实体手机或真实儿童环境验收**。没有为了验收开启物理麦克风或改写真实孩子记录。首次离线使用需先完成资源下载。没有改启动器，因此未重跑 Python 启动器测试。

交付提交可用 `git log -1 -- docs/XIAOYA_SOUND_QA.md` 查询；构建哈希来自文件内容，重新 checkout 的换行字节可能影响构建指纹，不应手改版本文件伪装为同一包。
