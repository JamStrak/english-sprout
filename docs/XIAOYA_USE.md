# 小芽英语 v0.8.0 · 单击开口、每日复习与花园反馈

本轮在 `codex/xiaoya-garden-ab` 分支试用，尚未发布到原线上地址。面向 3–4 岁孩子，首轮由家长陪伴观察。原来的 A 花盆花园保留，新增 B 自由小花园供对比。

## 打开

实际工程为 `C:\Users\Jam\.codex\worktrees\xiaoya-english-design\儿童英语练习`，分支 `codex/xiaoya-garden-ab`。双击这里的 **启动小芽英语.vbs**。启动器复用本目录已有服务；常用端口 24756，冲突时自动选 24757–24766。普通使用不需要终端。首次没有构建时自动构建；缺少本机 Python 或 Node 会给出提示。电脑重启后需要再次双击启动，单独打开旧浏览器地址不会启动本地服务。`E:\AI新项目\其他实验\儿童英语练习` 是旧英语小芽主目录，不是本版源码。

本电脑入口：`http://127.0.0.1:24756/xiaoya/`。手机、平板实际安装使用需要后续 HTTPS 托管；桌面浏览器的触屏视口检查不代表实体设备验证。

默认进入 A；家长区“花园 A / B 体验”可以选择并保存以后使用的版本。也可通过以下地址临时预览，不覆盖已保存的偏好：

- A 花盆花园：`http://127.0.0.1:24756/xiaoya/?garden=a`
- B 自由小花园：`http://127.0.0.1:24756/xiaoya/?garden=b`

带参数的地址刷新后仍预览指定版本；去掉 `garden` 参数后使用家长保存的选择。家长区再次选择版本会移除当前地址的临时参数。若启动器使用了备用端口，相应替换地址中的端口。

首页仍只有一个主要入口，图画会随安排的故事变化；到期先复习，连续复习两句后穿插一个新故事。已有进度不用重置：家长区顶部显示待复习和未玩数量，并有醒目的“试一个新故事”入口；完整 42 个故事列表收在可展开的区域。`?story=hello-goodbye` 只在尚无已完成练习记录时指定第一个故事，之后由练习安排接管。

## 孩子的完整循环

1. 首页只有一个主要出发按钮，不列主题。看完四个连续漫画镜头，在对应需求出现时听英语，然后点亮话筒尝试说。共有 42 个生活故事、40 句口语，涵盖打招呼、吃饭、照顾自己、一起玩、外出和睡前；最先遇见要水、请帮忙和送玩伴回家。
2. 看完故事后，点一次话筒就进入录音准备，不再需要先点一下切换页面、再点一下才能录音。首次需大人确认本机录音并处理浏览器权限，同意后自动继续刚才的录音请求。已授权时在故事看完后提前准备设备；等待中立即显示转圈，真正录上后才亮起话筒邀请说话。停顿后自动结束，再点一次也可结束，最长 12 秒。练习页唯一的小耳朵重播英语示范，问号听中文帮助；带回转箭头的话筒回听自己的录音，喇叭重播本次反馈。
3. 说完自动得到词句匹配星星。不愿说、设备无法录音或识别没准备好时，可以点小三角，完整听伙伴示范后继续参与。不会被认定为独立会说。
4. 完整参与一次，领取 **3 枚贝壳**，以及 A 的 **2 滴水**或 B 的 **5 滴水**。进入小花园，用 3 枚游戏贝壳打开一袋种子，再种花、浇水。
5. 小花一直保留，可以反复玩故事，把花园慢慢种大。两种玩法都没有真钱购买或付费抽取；贝壳、水和花朵表示参与，不表示口语掌握。

新手通过主要按钮、手势、图标和预制语音学习操作。种过 3 株后，不再每步重复语音和手势；在花园停顿 15 秒时再提示一次，继续操作后重新计时。问号随时可以主动求助。待种时先展示种子，种下后逐步发现花的样子；已经开花的花朵可触摸获得反馈。旧听音选图、家具摆放和字母探索不再出现在这一版儿童流程中。

花园资源和待种的种子实时保存；刷新或关页不会重复扣费、发奖。练习已保存但奖励保存中断时，重开会按原花园补回应得贝壳和水；不会因切换 A/B 重复发奖。故事中途刷新会回首页重新开始，临时录音不保存。

按钮有触点和按压反馈；贝壳到账、开种子袋、播种、浇水、开花有不同的短音和小动效。它们在本机合成，不增加音效下载包。录音和语音播放时停止提示音，避免影响听说；系统设置“减少动态效果”时保留静态反馈。

## 复习怎样安排

首次完成故事后，次日再邀请孩子回想。复习先展示需求情境，直接邀请开口，不提前播放目标英语；已有可靠独立表达观察的故事会使用另一情境。孩子可以主动听示范或中文帮助，使用后按有帮助表达记录。

到期复习有独立表达候选时，间隔按 1、3、7、14、30 天逐步延长；只是听过、需要帮助或未表达出来，次日继续安排。同一天重复练习不会越级拉长间隔，漏学后按真实日期接续。复习两句后穿插未玩过的故事，全部到期内容完成后继续新故事；全部玩过且没有到期复习时，仍可自由重玩。

这些间隔是产品采用的复习节奏，并非测得孩子的个人遗忘速度。机器匹配可以辅助安排复习，但不会写成“家长确认独立掌握”；家长更正会参与后续安排。家长区可查看每句上次练习、下次复习和当前间隔。两座花园共享安排，v0.7 的奖励记录、旧完成记录和家长观察会用于识别已经接触的故事。

## 两座花园怎样玩

| | A · 花盆花园 | B · 自由小花园 |
| --- | --- | --- |
| 完整参与一个故事 | 3 枚贝壳、2 滴水 | 3 枚贝壳、5 滴水 |
| 一袋种子 | 3 枚贝壳 | 3 枚贝壳 |
| 播种 | 点空花盆 | 拿起种子，再点草地想种的位置；也可拖到草地 |
| 浇水 | 两次开花 | 拿起水壶，再点或拖到小苗，每次消耗一滴水、长大一点 |
| 开花所需 | 2 次 | 普通花及蝴蝶结花 5 次，巨型花 10 次 |
| 花朵种类 | 6 种 | 12 种，可查看花朵收藏 |

A 保留雏菊、郁金香、向日葵、风铃花、虞美人、紫罗兰及原存档。B 在这 6 种之外，增加粉、蓝、金黄、紫 4 色蝴蝶结花，以及巨型雏菊、巨型向日葵。巨型花需要多次故事带回水，成熟后明显更大；缺水时点小三角再玩一个故事。

种子按固定顺序轮换，不是随机抽取。B 的一轮顺序是：雏菊、粉蝴蝶结、巨型雏菊、蓝蝴蝶结、郁金香、金黄蝴蝶结、向日葵、紫蝴蝶结、风铃花、巨型向日葵、虞美人、紫罗兰。前 6 袋内会遇见一株巨型花和 3 色蝴蝶结；一轮结束后重新开始。打开种子袋后品种已经确定，刷新不会换种子。

A、B 分别保存贝壳、水、待种种子、花朵和奖励账本，切换不会搬走或清空另一座花园的资源。学习观察、词句证据、故事推进和英语声音选择共用；在 A 玩过的故事，换到 B 不会被当作全新进度，也不会自动再发一份奖励。B 当前没有固定花盆或栽植数量上限。

## 三种英语声音

家长区的“选择说英语的伙伴”可试听并保存小熊伙伴、小狐伙伴、泡泡猫三种现有声音，默认泡泡猫。选择后，42 个故事及英语示范一起使用所选声音，切换花园不改变声音。中文操作引导仍使用独立预制配音。

## 家长怎样验收

自动星星表示本机识别出的词句与目标表达的匹配程度，不是音素级发音准确率；未识别到也不等于孩子一定说错。识别未就绪时不给假分，可以重试或先听先说。识别器先独立听写录音，再对照允许的表达；不把目标答案交给识别器补全。小声录音会做本地音量调整，静音与持续白噪声不按正确回答处理。

家长区分别显示参与次数、机器候选、家长确认独立表达与跨日换情境证据。42 个故事均可“生活验收”：先展示不同情境，只邀请孩子开口，不预先播放目标句或中文答案。用过示范或中文帮助的当次记录只能是有帮助表达。可靠独立观察后，后续验收会切换情境；不同日期、不同情境的确认才能形成稳定表达证据。

家长可接受意思合适的短表达；只有明确听到完整原句才勾选原句。旧观察可核对、更正，原始记录与更正轨迹保留。如果已有多次参与却没有合适表达记录，家长区会提醒关注；未开启识别或未做观察也可能出现这种提醒，不能据此断定孩子学不会。

## 声音、离线与记录

- 英语复用已有三种配音；中文使用制作期生成的静态神经语音文件。v0.7 新增 56 条中文配音：24 个新增故事各有两种情境帮助，共 48 条，另有 B 花园的 8 条操作引导，合计约 1.79 MiB。运行时不生成声音、不连接配音服务、不调用付费 API。
- 花园与多数故事使用轻量 SVG；42 个故事中，最先的 3 个使用漫画 WebP，合计约 506 KiB，其余使用矢量分镜。首页展示下一故事的一幅画，首次只缓存页面和必要程序，不下载所有漫画、所有声音或识别模型。
- 英语、中文引导和漫画均按实际访问下载，缓存成功后才支持离线再用；新 56 条配音也遵循这一规则，不会在第一次打开时全部下载。切换英语伙伴后，另一种声音也需要先播放、缓存。准备离线试玩时，先在服务可访问时走完想玩的故事与花园操作；只打开首页并不代表所有声音已准备好。
- 首次录音按需准备约 81 MB 本地 Whisper 识别资源；准备中仍可录音、回听、听示范，准备好后可离线识别。浏览器清除或回收缓存后需要重新下载。日常本机使用请保持本地服务运行；重启电脑后重新双击启动入口。
- 录音和原始转写只在本机内存中处理，不上传、不进导出文件；离开或页面进入后台时释放。
- 已授权后的设备预热可能点亮浏览器或系统的话筒指示灯；此时不创建录音器、不保存声音，点击才开始录音。闲置 20 秒、退出说话环节或切到后台会关闭设备。不支持查询权限的浏览器仍在点击后准备。
- 学习观察、每日练习安排、A/B 两座花园、版本选择和声音偏好保存在当前浏览器，家长区可以一并导出。旧观察、家具和字母记录仍保留。没有新版导入或跨设备同步入口，清理浏览器数据会丢失本机记录；更换浏览器或服务端口也不会自动带入原记录。
- v0.8 是本机试玩版本；真实儿童对 42 个故事的辨图理解、两种花园的操作理解、开口意愿、识别准确率和长期学习效果仍需实际试玩。本说明不代表这些效果已经验证。
