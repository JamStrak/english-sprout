# 小芽英语 v0.1.0 · 本地试玩

本版本在 `codex/xiaoya-english` 独立分支开发，尚未发布到原线上地址。面向 3–4 岁孩子，建议首轮由家长陪伴观察。

## 打开

双击项目内的 **启动小芽英语.vbs**。启动器会打开浏览器，复用本工作目录已有服务；常用端口为 24756，冲突时自动选 24757–24766。普通使用不需要终端。首次没有构建时会自动构建；需要本机 Python 和 Node，缺少时有提示。

本地常用入口：`http://127.0.0.1:24756/xiaoya/`。该地址只供本电脑使用。手机、平板真正安装试玩需要后续 HTTPS 托管；本轮仅完成桌面浏览器的手机和平板视口测试。

## 给孩子玩

1. 首次由家长选择允许录音，或先听和玩。
2. 首页六幅画分别进入见面、吃喝、一起玩、自理、外出、睡前主题。普通儿童游戏不显示英文字母。
3. 小耳朵播放英语示范，问号提供中文语音帮助。初次先听声音找图，再尝试交流。
4. 点一下大话筒开始，停顿后自动结束；再点一次也可结束，最长 12 秒。回转箭头回听，家长图标记录真实表现，播放图标允许先看伙伴示范。
5. 完成事件可获得固定家具，放进小屋。点选家具再点落点，或拖动已摆好的家具；每事件只发一件，不靠重复领取刷收藏。

可以暂时不说、继续玩。家具表示参与，不表示听懂或会说。录音只供本轮回听，退出或页面转入后台即停止并释放，不进存档、不上传。

## 家长怎样验收

家长区分别展示听懂、有帮助说、独立说、隔天换情境说。选择题只记录听辨；机器词句匹配只记录待确认候选。稳定的口语表现需要家长在不同日期、不同实际情境下观察确认。

每个事件提供「说」和耳朵回访入口。说话回访不先播放答案；使用示范或中文提示后，本次只能记录为有帮助表达。家长可以接受意思合适的短表达；只有明确听到完整原句时才勾选原句。旧观察可以更正，保留原记录与更正轨迹。

如果跨日持续参与而缺少口语观察，或连续观察仍没有独立表达证据，家长区会提醒调整邀请方式。不会因为一直玩就自动宣称学会。

求助、表达需要、邀请共玩三个核心目标有跨日换情境证据后，家长可以开启独立的小符号探索区。26 个字母均有发现活动，找图后还需本地匹配候选或家长确认表达才能领取。收齐后，某句还需自己的跨日、换情境完整原句证据，才显示该句拼写。收藏本身不增加口语能力。

## 声音、离线与记录

- 英语复用原项目 Pip 已有配音；中文帮助为本机系统语音预制文件。未接入付费运行 API。
- 首页核心资源约 160 KB；短音频按需加载并保存离线，不一次下载全部内容。已播放声音仍需缓存成功，且浏览器未清除缓存，才能离线使用。
- 可在家长区明确选择准备约 47 MB 本地识别资源。没有下载也能听、录音、回听和完成亲子验收；识别不代表发音准确率。
- 新版学习记录独立保存在当前浏览器，可在家长区导出。首版没有跨设备同步或新版导入入口，清理浏览器数据会失去本机记录。
- 包含6主题、18事件、36情境和18家具。数值门槛及中文帮助、美术、节奏均为第一轮试用版本；尚未验证真实儿童识别准确率和长期学习效果。
