# 小芽英语 v0.6.1 · 漫画花园与本地识别

在 `codex/xiaoya-english` 独立分支开发，尚未发布到原线上地址。面向 3–4 岁孩子，首轮由家长陪伴观察。

## 打开

双击项目内的 **启动小芽英语.vbs**。启动器复用本目录已有服务；常用端口 24756，冲突时自动选 24757–24766。普通使用不需要终端。首次没有构建时自动构建；缺少本机 Python 或 Node 会给出提示。

本电脑入口：`http://127.0.0.1:24756/xiaoya/`。手机、平板实际安装使用需要后续 HTTPS 托管；桌面浏览器的触屏视口检查不代表实体设备验证。

已有进度可从家长区指定重玩三个故事，不需要重置存档。`?story=hello-goodbye` 只在尚未获得花园奖励时指定第一个故事，之后首页按照花园进度继续。

## 孩子的完整循环

1. 首页只有一个主要出发按钮，不列主题。看完四个连续漫画镜头，在对应需求出现时听英语，然后点亮话筒尝试说。当前三个故事是要水、请帮忙和送玩伴回家。
2. 第一次点话筒，请大人确认本机录音并处理浏览器权限。已授权时会在进入说话环节提前准备设备，减少点击后的等待；等待中显示转圈，话筒亮起后再说。停顿后自动结束，再点一次也可结束，最长 12 秒。练习页唯一的小耳朵重播英语示范，问号听中文帮助；带回转箭头的话筒回听自己的录音，喇叭重播本次反馈。语音指令会让对应按钮亮起。
3. 说完自动得到词句匹配星星。不愿说、设备无法录音或识别没准备好时，可以点小三角，完整听伙伴示范后继续参与。不会被认定为独立会说。
4. 完整参与一次，领取 **3 枚贝壳和 2 滴水**。点花朵进入小花园，用 3 枚贝壳打开种子惊喜包，点花盆种下去，再浇两次水开花。
5. 六种花依次出现：雏菊、郁金香、向日葵、风铃花、虞美人、紫罗兰。全部遇见后再开始一轮；没有购买入口或付费抽取。小花一直保留，可以反复玩故事，把花园慢慢种大。

新手通过主要按钮、手势、图标和预制语音学习操作。种过 3 株后，不再每步重复语音和手势；在花园停顿 15 秒时再提示一次，继续操作后重新计时。问号随时可以主动求助。待种种子只展示种子，点唯一的空花盆种下后再逐步发现花的样子；已经开花的花朵可触摸获得绽放和声音反馈。贝壳和水表示参与，不表示口语掌握。旧听音选图、家具摆放和字母探索不再出现在这一版儿童流程中。

花园资源和待种的种子实时保存；刷新或关页不会重复扣费、发奖。故事中途刷新会回首页重新开始，临时录音不保存。

## 三种英语声音

家长区的“选择说英语的伙伴”可试听并保存小熊伙伴、小狐伙伴、泡泡猫三种现有声音，默认泡泡猫。选择后，三个故事及英语示范一起使用所选声音。中文操作引导仍使用独立预制配音。

## 家长怎样验收

自动星星表示本机识别出的词句与目标表达的匹配程度，不是音素级发音准确率；未识别到也不等于孩子一定说错。识别未就绪时不给假分，可以重试或先听先说。识别器先独立听写录音，再对照允许的表达；不把目标答案交给识别器补全。小声录音会做本地音量调整，静音与持续白噪声不按正确回答处理。

家长区分别显示参与次数、机器候选、家长确认独立表达与跨日换情境证据。三个故事均可“生活验收”：先展示不同情境，只邀请孩子开口，不预先播放目标句或中文答案。用过示范或中文帮助的当次记录只能是有帮助表达。可靠独立观察后，后续验收会切换情境；不同日期、不同情境的确认才能形成稳定表达证据。

家长可接受意思合适的短表达；只有明确听到完整原句才勾选原句。旧观察可核对、更正，原始记录与更正轨迹保留。如果已有多次参与却没有合适表达记录，家长区会提醒关注；未开启识别或未做观察也可能出现这种提醒，不能据此断定孩子学不会。

## 声音、离线与记录

- 英语复用已有三种配音；中文使用制作期生成的静态神经语音文件。运行时不生成声音、不调用付费 API。
- 首页和花园使用轻量 SVG；三组漫画 WebP 合计约 506 KiB，进入对应故事时才加载。首次首页不下载所有漫画、所有声音或识别模型。
- 短音频与漫画缓存成功后支持离线再用。首次录音按需准备约 81 MB 本地 Whisper 识别资源；准备中仍可录音、回听、听示范，准备好后可离线识别。浏览器清除缓存后需要重新下载。
- 录音和原始转写只在本机内存中处理，不上传、不进导出文件；离开或页面进入后台时释放。
- 已授权后的设备预热可能点亮浏览器或系统的话筒指示灯；此时不创建录音器、不保存声音，点击才开始录音。闲置 20 秒、退出说话环节或切到后台会关闭设备。不支持查询权限的浏览器仍在点击后准备。
- 学习观察、花园和声音偏好保存在当前浏览器，家长区可以导出。旧观察、家具和字母记录仍保留。没有新版导入或跨设备同步入口，清理浏览器数据会丢失本机记录。
- 本轮先完成三个故事的闭环；真实儿童的辨图理解、开口意愿、识别准确率和长期学习效果仍需实际试玩。
