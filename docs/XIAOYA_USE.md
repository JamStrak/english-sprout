# 小芽英语 v0.4.0 · 本地试玩

本版本在 `codex/xiaoya-english` 独立分支开发，尚未发布到原线上地址。面向 3–4 岁孩子，建议首轮由家长陪伴观察。

## 打开

双击项目内的 **启动小芽英语.vbs**。启动器会打开浏览器，复用本工作目录已有服务；常用端口为 24756，冲突时自动选 24757–24766。普通使用不需要终端。首次没有构建时会自动构建；需要本机 Python 和 Node，缺少时有提示。

本地常用入口：`http://127.0.0.1:24756/xiaoya/`。该地址只供本电脑使用。手机、平板真正安装试玩需要后续 HTTPS 托管；本轮仅完成桌面浏览器的手机和平板视口测试。

本轮漫画试点可直接打开 `http://127.0.0.1:24756/xiaoya/?story=hello-goodbye`，点唯一主按钮开始。可在已有进度下重看，不需要重置存档。

## 给孩子玩

1. 第一次打开只看到小芽和一个醒目的主操作；首页和练习页的说明不再用可见段落占据视线。点小芽进入引导，无须先选择主题、录音或下载识别资源。
2. 按语音和手势依次操作：点耳朵听英语 → 点小手打招呼 → 点话筒尝试说 → 听自己的声音 → 领取小太阳 → 点发光位置放好。每一步只有一个主要目标，声音播放结束后才开放下一步。
3. 第一次点话筒时，请身边的大人完成录音选择。等话筒亮起再开口；点一下开始，停顿后自动结束，再点一次也可结束，最长 12 秒。录音不会等待音量分析器启动，避免因此漏掉句首。设备不能录音、拒绝权限或暂时不想说，都可以先听伙伴示范继续参与。
4. 首轮中途退出或刷新，下次从已经保存的步骤继续；录音不会保存，离开后需重新说一句。引导点击和录音尝试不记作听懂或会说。
5. 首轮后首页仍只有一个主要的下一段故事入口，按生活事件逐步推进；完成三个不同事件后才显示自由选择主题的入口。普通儿童游戏不显示英文字母。
6. 「送玩伴回家」先看四个连续漫画镜头：一起玩、准备离开、门口挥手、走远；到挥手时才听到英语。完整看完再邀请孩子参与告别，不要求零基础孩子先猜意思。可重看或听中文帮助；看完后的表达记为有帮助练习，不计独立听懂或独立会说。完成事件、领取家具不会跳过这段教学；已有可靠独立表达观察时才允许普通重访省略教学。家长主动验收仍保留无答案提示的听说回访。
7. 其他事件暂时沿用上一版：听辨题显示中性的小芽，听完从不同图片中选择。表达时用话筒说话，录完自动识别并用 0–3 颗星反馈本次词句匹配；可重录或点带耳朵的小芽求助。告别试点的求助会回到漫画，其余事件播放中文引导和英语示范。本轮未把全部 18 个事件改成漫画教学。
8. 不同生活短句和迁移情境用不同人物动作、物品或背景表达含义；明确复用的拉外套拉链情境沿用相同场景。完成事件的固定家具可以放进小屋，每事件只发一件。摆放后点下方小房子回首页，并听到继续邀请。

操作由录制语音、耳朵/话筒/礼物图标和手势动画指引；录音准备与正在收音有不同视觉状态。普通事件的星星旁带耳朵，点一下可重听反馈，不重复评分或记成绩；首次教学中点击星星旁的耳朵重听当前步骤提示。家长入口及权限、存储故障说明保留文字；后期奖励区解锁的短句可点播。

可以暂时不说、继续玩。家具表示参与，不表示听懂或会说。录音只供本轮回听，退出或页面转入后台即停止并释放，不进存档、不上传。

## 家长怎样验收

孩子每次开口可直接获得自动反馈，无须家长逐次打分。星星表示本机识别出的词句与目标表达的匹配程度，不是音素级发音准确率；没识别到不等于孩子一定说错。未准备好的识别功能不打分，提供重试和示范入口。

家长区分别展示听懂、有帮助说、独立说、隔天换情境说。选择题只记录听辨；机器词句匹配只记录待确认候选，不直接解锁稳定掌握。稳定的口语表现仍需要家长在不同日期、不同实际情境下观察确认。

每个事件提供「说」和耳朵回访入口。说话回访不先播放答案；使用示范或中文提示后，本次只能记录为有帮助表达。家长可以接受意思合适的短表达；只有明确听到完整原句时才勾选原句。旧观察可以更正，保留原记录与更正轨迹。

如果跨日持续参与而缺少口语观察，或连续观察仍没有独立表达证据，家长区会提醒调整邀请方式。不会因为一直玩就自动宣称学会。

求助、表达需要、邀请共玩三个核心目标有跨日换情境证据后，家长可以开启独立的小符号探索区。26 个字母均有发现活动，找图后还需本地匹配候选或家长确认表达才能领取。收齐后，某句还需自己的跨日、换情境完整原句证据，才显示该句拼写。收藏本身不增加口语能力。

## 声音、离线与记录

- 英语复用原项目 Pip 已有配音；中文引导改为预制的神经语音文件，内容明确说明要点哪里、做什么，运行时不生成语音、不调用付费 API。
- 首页使用轻量 SVG 和样式动画；告别漫画整组 150,210 字节，进入故事才加载。短音频和漫画缓存成功后可离线再用，不一次下载全部内容；浏览器清除缓存后需要重新联网。替换后的中文使用独立新版缓存，保留已下载英文的复用。
- 第一次录音时自动准备约 47 MB 的本地识别资源，首页不提前下载。准备中仍能录音、回听和听示范；若这段录音还在当前流程，准备完成后自动识别。失败可重试，也能先参与；资源缓存成功后可离线识别。转写只在本机内存中处理，不进入存档。
- 新版学习记录独立保存在当前浏览器，可在家长区导出。首版没有跨设备同步或新版导入入口，清理浏览器数据会失去本机记录。
- 包含6主题、18事件、36情境和18家具。数值门槛及中文帮助、美术、节奏均为第一轮试用版本；尚未验证真实儿童识别准确率和长期学习效果。
