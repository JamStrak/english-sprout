## 验收系统：已确认要求与拟议方法

用户明确要求能够判断是否学会、学会多少、程度如何，并避免孩子掌握不足而系统持续推进。家长参与和核心目标进阶规则已确认；下列细节为待纳入整体评审的具体设计。

### 分开记录能力证据

- 听懂：能根据语音在情境中做出合适反应。画面不能单独泄露正确答案，需要变换位置、物品或情境后再观察。
- 有帮助的表达：听示范后跟说，或获得中文、英文帮助后表达。帮助方式需要记录。
- 独立表达：没有先播放目标答案，在适当情境中自行表达意思；接受阶段内定义的合理表达。
- 保持与运用：在另一天或不同情境中仍能理解、独立表达。
- 发音质量：不能把识别到目标词句等同于专业发音评估或纯正口音认证。

即时跟读、图画选择、首次独立表达、跨日再次表达分别记载；当场提示后重做正确不覆盖首次观察。暂未开口、没有观察机会、录音失败和识别不清与实际理解错误分开。

### 观察与进阶

- 日常互动持续收集表现，小阶段设置专门的生活挑战，之后进行延迟回访。
- 儿童看到可以参与的生活事件；家长能够看到验收目标、证据来源、时间和不确定性。
- 家长选择具体行为状态，例如“自己说出来 / 提示后说出来 / 暂未观察到 / 没听清”，不以一个任意的“通过”按钮替代观察。
- 家长不需要专业发音打分；提供帮助仍可继续活动，但应保留帮助发生的事实。
- 核心目标不足时继续提供不同情境与支持，暂缓增加依赖这些基础的语言难度。听懂与会说分别记录。
- 长期缺少开口证据时，改变邀请表达的方式、降低当前表达要求，并向家长说明情况；不继续宣称新增口语掌握。
- 频率、稳定通过次数和阶段门槛仍待设计及真实试用验证，不能把随意设定的次数当作经过验证的儿童能力标准。

参考原则：[NAEYC 幼儿观察、记录与评估](https://www.naeyc.org/resources/position-statements/dap/assessing-development/)。它支持情境化、多次、多来源的观察原则，不是对本产品评估算法或效果的验证。

## 一段完整体验的拟议串联

以下以“一起玩”为例，仅为待评审的事件脚本；已确认的按钮收音、中文帮助、自由选主题和验收要求应用于其中。

1. 孩子从六个图画入口选择一起玩，进入伙伴身边的玩具场景。系统按当前表现选取事件与帮助程度。
2. 初次学习时，伙伴遇到打不开的玩具盒，通过动作与英语求助示范建立意思；孩子帮助伙伴打开，观察请求与结果的联系。需要时提供中文语音帮助。
3. 接着孩子想玩的另一个玩具盒也需要协助。伙伴留出表达机会，孩子点一下大图形按钮，提出自己的请求。拟接受意思相符的短表达，如 Help me / Help, please，不要求一开始逐字复述完整句。具体表达清单待课程设计。
4. 表达意思得到可靠确认时，伙伴回应并帮忙，继续共同玩耍。没收到回答、录音不可用或识别不清时，保留重说、求助或图画表达的路径；使用这些路径的帮助事实单独记录。仅检测到声音不算已经理解请求，也不算口语掌握。
5. 示范后说出来记为有支持的表达。这一事件自然结束，可留下共同玩过的纪念；另一天在不同事件中安排没有先给答案的表达机会，并结合家长观察进行验收。
6. 首次授权、录音准备和识别准备分别呈现真实状态。孩子点按钮后先给清楚的收音提示，结束后显示处理状态；自动结束的停顿容错与超时需要设备原型验证，不能在设计稿中当作已可靠实现。

已确认的长期吸引方式：以建设自己的小屋、逐步收集家具、玩具与装饰并自由布置为主。参与留下的纪念与听说能力证据分开，字母彩蛋仍放在已确认的后期独立探索区。具体奖励规则见整体审阅稿，尚未逐项确认。

## 加载与表现：拟议的首版约束

用户确认的是快速上手、避免明显等待和卡顿。以下是拟采用的实现方向，尚未开发或测量：

- 用轻量二维素材、适量层次和短动效表现玩具触感；实时复杂三维或大视频不作为风格的必要条件。
- 首次优先准备第一段可完成的事件，包括所需图片与少量声音；后续场景、非当前角色配音和文字探索资源按需获取。
- 同时关注首次可用所需下载量、后续使用的等待和可选离线资源总量，不能只报一个压缩包数字。
- 避免“打开很快、每句话都等下载”：当前短事件所需声音应在合适时机准备，衔接与回放纳入验证。
- 识别资源不应阻塞所有听、玩及亲子观察功能；未就绪时如何邀请说话、如何回应、如何诚实记录证据，需要在完整流程中设计。
- 首次冷启动、缓存后重开、场景切换、首次播放、录音准备及持续动画分别检查；手机、平板和较慢网络均纳入验证。
- 具体设备、网络条件、体积预算和时延门槛在原型测试计划中定义。未测量之前，不承诺“秒开”或“无卡顿”。

当前基线的实际文件：`public/speech/model-en-us-0.15.tar.gz` 为 41,184,862 字节，`public/speech/vosk-0.0.8.js` 为 5,805,300 字节。这是本地文件大小，不是实际网络传输量。旧识别资源是首次使用的重要风险，不能未经评估照搬其加载路径。
