# 小芽英语 · 章节学习交接

更新：2026-10-22，v0.27.0。正式工程、当前构建与交付提交入口见 [当前状态](../PROJECT_CONTEXT.md)。章节于 v0.26.0 接入；用户确认练习后宽松开放下一章，挑战用奖励吸引主动参加。v0.27.0 强化章节地图的单一推荐焦点，不改变开放或学习证据规则。

## 已实现的规则

- 84 句核心表达沿用顺序、事件/表达 ID，组成 21 章，每章四句；分别对应既有 `challenge-1` 至 `challenge-21`，不重排旧挑战。
- 四句都完成练习参与，下一章从灰色变为彩色。无需三星、无需通过挑战。一次低星尝试可选择“练过啦，继续”；纯静音、没有识别结果或设备失败不自动记完成，可以主动听完整示范后继续参与。
- 章节参与与“独立会说”分开。低星/示范参与不升级口语证据，不延长成已掌握的复习间隔。
- 进度读取现有练习卡 `firstDate`，无新持久化键。已有后面章节练习记录的老用户，保留到最远已练章节的访问权限；不清存档、不重新锁住旧内容。
- 挑战可选；每章详情直接展示对应的目标花。原规则保持：同句三星一次、两星累计两次通过，一星继续练；首通按已保存数值发贝壳、水和种子，同关不重复发奖。

## 操作和复习

首页提供「学习」和「花园」两张可点击纸艺插画。学习进入章节地图；章内四张图片沿用练习时的熟悉情境。可以自由选择本章某句，也可用主按钮按未练顺序继续。领奖后可以继续本章或进入花园，四句练完显示下一章入口。

地图只强调一张“从这里继续”推荐卡：进入时立即显示明显的光圈和播放图标动效，并将推荐卡滚动到可见位置。动效落在实际可点击的卡片范围，不只靠文字、卡片加长或细外框；其他已开放章节仍可自由选择，不一起闪动。系统开启减少动态效果时，停止循环动画，保留静态高对比轮廓与播放图标。

这属于进入章节后的导航焦点，不等待空闲提示计时。一般操作提示仍遵守连续 30 秒无操作才出现按钮光圈、60 秒后才可语音提醒；不要为加强章节指引而让所有按钮常闪。儿童相关提示统一遵循“明确动态视觉焦点、单一推荐、可点目标区域”的设计准则，见 [交互约束](XIAOYA_DESIGN.md#6-引导反馈和视觉的交互约束)。

“再练练”只收集该章已练句，优先到期内容；单句复习和队列复习都不自动播英语答案。间隔仍来自已有的本地日历安排，通常 1/3/7/14/30 天，听过/需帮助次日再练。章节继续优先新句，原家长区的两次复习穿插一次新学保留。

完成第 3、6、9……章及前面所有章节后，出现“老朋友聚会”，从最近三章取四句，至少覆盖每章一句，再按到期/时间排序。使用练习卡中熟悉的事件和图。**这是混合复习，不是跨章混合考试**，不写挑战通过记录。

| [chapters.css](../xiaoya/chapters.css) | 双入口及章节响应式样式、推荐卡动效和减少动态效果适配，最后加载覆盖旧首页布局 |
| [experience.js](../xiaoya/experience.js) | 路由、推荐卡入页可见、单句/队列会话、领奖后继续、低星参与出口 |
| [章节单测](../tests/xiaoya-chapters.test.js) | 映射、宽松开放、老记录、选句、复习覆盖 |
| [浏览器检查](../tests/xiaoya-chapters-browser.cjs) | 两种视口、点击/触摸、低星及失败路径、复习与证据隔离 |

`startEvent` 第五参数携带 `{chapterId, kind}` 的 `learningRoute`；不要把临时队列写入新学习存档。`chapterAfterReward` 处理队列推进、章完成或回详情。低星出口必须检查真实尝试 ID，避免纯录音失败刷完成。`data-chapter-phrase` 的处理必须在通用 `data-chapter` 前，因为单句按钮同时有两者。所有状态仍走 `appStorage`，GM 测试只用内存沙盒。
