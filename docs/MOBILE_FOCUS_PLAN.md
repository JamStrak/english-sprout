## 已实现的使用顺序

首页只突出一个当前任务，按「到期复习 → 今日新句 → 到期记忆小游戏 → 花园」选择。孩子点大图或主按钮即可开始，不需要下拉寻找复习入口。完成一类任务后重新读取日历安排，再给下一步；当天复习会影响小测候选，不复用旧候选快照。底部导航和完成页的休息入口保留自主选择。

`src/journey.js` 只组织顺序，复用 `src/learning.js` 的计划；不重复实现日历规则，不改既有课程 ID、学习记录、复习上限或奖励算法。错过日期不跳过新课；达到当天复习上限后，不为清空积压而继续塞入复习。

## 每屏只做一件事

- 练习分为听、听音选图、说、回想。大图可播放，主要动作和即时反馈在当前屏内；录音是可选的本机回听。复习和小测进入时不自动放答案，主动听提示会揭晓；小测听过提示后不能选择“自己会说”。
- 首页及练习点「换伙伴 / 语速」打开面板，直接点 Aiden / Ryan / Pip 名字试听，直接点四档语速变速；不使用音色下拉框。临时慢听也在练习声音面板，中文帮助仍需手动点。
- 小书先选主题，每页六个；主题内每页四句；全局搜索每页两句。上下页通过按钮切换，不把 120 句堆成滚动长页。
- 花园一次只展示一块地，三个按钮切换地块，每块地只展示当前可做的一个动作。植物图鉴独立一屏；种子、水滴、肥料及收集记录保留。
- 家长页先按六个用途进入独立子页。声音、离线下载、备份、学习足迹不混在同一屏；安装/二维码在离线子页进入，关于与隐私在陪伴方法中进入。
- 头像可一键选预设动物；自拍按「选照片 → 选头套 → 可选调整小脸 → 保存」分步。上传/拍照入口、动物选择和裁剪滑杆按步骤呈现。
- 配音对照留在家长的声音子页，兼容 `?audition=1`。四位候选样音和原两位角色可在已测最小手机视口内点到，无需中间滚动；只有 Pip 加入完整课程，其余候选没有扩充。

## 数据与学习边界

三位正式角色各有完整 120 句；本轮没有重制音频或新增角色。学习进度、声音偏好、头像仍各自保存在本机。录音不上传、离开练习卡即清理；自拍不进入学习备份。间隔复习和回想的研究依据沿用 [DESIGN.md](DESIGN.md)，没有将选择题答对或家长反馈标成自动发音评分、完全掌握认证。
