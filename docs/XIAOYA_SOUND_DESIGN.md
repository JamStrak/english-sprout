# 小芽英语全流程声音设计

版本：v0.25.1；核对日期：2026-10-21。本轮把点击、页面切换、学习、奖励、商店、花园和家长设置整理为 **31 个声音使用点：30 个交互音效、1 个花园背景音乐**。17 段短音效来自用户的声匣工具；仅花园使用项目原有钢琴。默认开启 30 个使用点，录音结束提示默认关闭。

配置的唯一目录是 [`sound-catalog.js`](../xiaoya/sound-catalog.js)，实际触发接入 [`experience.js`](../xiaoya/experience.js)。资源候选、选择理由、时长、授权和检验方法见[音效筛选记录](XIAOYA_SOUND_SELECTION.md)；逐文件来源和哈希见[筛选数据](../design/xiaoya-sound-selection.json)。本文件说明使用方式，不重复来源表。

## 用户声音开关与提示时机

顶栏设置的 `preferences.audioControls` 包含 `music`（音乐和音效）与 `reminders`（自动人声提醒），缺失时均为 true。此总门控不覆盖 GM 保存的素材、音量或使用点开关。关闭 music 会取消正在播放或等待解码的 SFX 和 GM 音效预览，花园 BGM 则在约 600ms 内淡出后暂停；旧异步完成不能重新出声。重新打开沿用原配置。reminders 关闭时停止当前自动语音并抑制后续主动操作、问候和鼓励；主动点英语示范、帮助、回听与声音试听仍可播放。

`guidance-policy.js` 记录首个会话和已讲过的操作情境；`guidance-clock.js` 分离视觉 30 秒与语音 60 秒空闲间隔；不显示小手，唯一推荐按钮闲置后显示轮廓光圈。新手首遍即讲，回访先静默；交互重置、后台/弹窗/GM 暂停，录音和忙碌状态不播。一次空闲提醒结束后再等完整 60 秒，不按播放起点抢跑。教学示范与庆祝反馈不等于操作说明；每日问候和达成反馈保留原触发，但服从 reminders 开关。两项个人偏好在 GM 沙盒继承后仅存内存，不随四类调参备份导入覆盖。

## 声音优先级与学习避让

英语示范、中文引导、儿童录音回听和麦克风使用优先。语音播放或回听开始时，正在播放的交互音效立即停止，期间的新音效请求直接跳过，不在语音结束后补播。录音准备、录音、等待和识别处理期间也暂停交互音效；录音开始没有提示音，准备好的提示保留视觉反馈。启用 `record-stop` 后，仅在有效录音结束、麦克风关闭后播放，再进入后续处理。

交互音效同时最多播放一段。优先级 4 的整组完成高于优先级 3 的奖励、揭晓和开花，再高于优先级 2 的流程反馈，普通点击为 1。已有声音优先级更高时，新的低优先级声音被跳过；同级或更高的新声音替换旧声音。BGM 使用独立循环播放器，目录中的优先级 0 不参与这一抢占比较。

同一使用点默认间隔至少 120 毫秒；条件不足为 400 毫秒、故事翻页和开花为 300 毫秒、轻触花朵为 250 毫秒、浇水为 220 毫秒。原生播放器预载并复用 17 段内置短音效（合计约 102 KiB），只加载、不自动播放；正常结束暂停并归零，避免常用点击重复冷启动。BGM 与上传素材按需加载释放。普通音效加载超时 1.2 秒，单次播放最多 2 秒；期间语音、录音或离页仍会立即取消，过期声音不补播。尚未完成的旧播放请求使用独立元素释放，不能干扰后续声音。已提供专属声音的操作不再叠加普通点击；播放语音和录音按钮保留各自反馈，不额外加入点击声。

背景音乐只在自由花园自动播放；首页、学习、挑战、商店和盲盒没有 BGM。进入花园用 600ms smoothstep 淡入，离开或打开弹窗、礼物、GM 时用 600ms 淡出至静音再暂停；快速来回切换取消旧渐变，从当前音量续接，复用同一播放器及播放位置。语音期间 120ms 降低音量、说完 600ms 恢复；录音及识别、后台和页面卸载仍即时静音，防止录入音乐或后台泄漏。GM 显式试听可播放所选声音。旧设置或旧备份里的 `bgm-home/shop/blindbox` 不再成为有效使用点，花园音量及其他配置保留。浏览器限制自动播放时，后续用户手势可以重试。

交互音效总开关默认开启，总音量默认 65%，最终音量为总音量乘以使用点音量。背景音乐沿用独立总开关和总音量，默认开启、50%；页面先乘使用点音量，再沿用播放器平方增益映射。背景音乐和交互音效的总开关互不代替。

三星、成功和奖励音效用于表达观察或流程反馈，不代表准确发音、已掌握口语或家长验收通过。资源不足采用短温和提示；不把反复失败警报作为学习反馈。

## GM 音效管理

打开 GM 调参工具，进入「音效管理」。页面按模块列出全部 31 个使用点，可按名称、触发位置、ID、素材名或路径搜索。每项显示当前素材、来源与授权、启用状态和音量，便于找到具体页面上的声音。背景音乐的总开关和总音量仍在「背景音乐」页；花园使用什么曲目、是否启用及使用点音量在「音效管理」中调整。

| 操作 | 实际效果 |
| --- | --- |
| 启用 / 禁用 | 暂停该使用点，保留素材绑定和音量，随时可重新启用 |
| 替换素材 | 从内置声音和已上传的本机素材中选择，修改后立即生效 |
| 删除配置 | 解除当前使用点的素材绑定，此处不再播放；使用点和素材库仍保留 |
| 添加声音 | 给未配置的使用点重新选择素材，或用「本机替换」上传并绑定；新增产品触发位置仍需在代码目录接入 |
| 本机替换 | 选择 MP3、WAV、OGG 或 M4A，通过格式、大小和浏览器解码检查后保存并绑定 |
| 使用点音量 | 单独调节这个使用点，不影响其他绑定同一素材的位置 |
| 试听 | 可检查已禁用的素材；先停止其他 GM 播放。交互音效最多 2 秒，BGM 最多 12 秒；再次点击可停止 |
| 恢复默认 | 恢复这一使用点的默认素材、开关和音量 |
| 全部恢复默认 | 恢复音效总设置和全部使用点；已上传的本机素材保留 |
| 删除素材 | 在「本机素材」中删除已经没有使用点引用的上传文件；仍被引用的素材需先解除绑定 |
| 导出配置 | 仍可单独下载 `小芽英语-音效配置.json`；v0.24.0 起请用 GM「数值与备份 → 导出全部参数」统一备份并还原四类配置，含音效设置和上传音频。旧单独音效 JSON 不是统一备份格式 |

试听会忽略启用开关，仍受使用点音量及对应总音量影响；BGM 试听与页面播放共用背景音乐总音量和增益曲线，音量为 0 时会提示提高音量。试听不改变学习记录、奖励或花园数据，也不自动改变启用状态。

普通模式修改自动保存在当前浏览器，存储键为 `xiaoya-english:sounds:v1`，刷新后继续使用。GM 模拟模式只在本次测试内生效，刷新后重置。上传仅将本机音频读入浏览器，不上传服务器；替换结果不会自动改写项目默认配置，也不会同步到其他设备或浏览器。

单个文件需大于 0 字节且不超过 **2 MiB**；整个音效配置序列化后最多 **5 MiB**。总量包含 Base64 编码开销和所有已上传素材，不能按原文件大小简单相加。浏览器共享存储额度可能更早耗尽；保存失败时保留之前有效的配置，并明确显示失败原因。未使用的本机素材可删除以腾出空间。导出文件包含本机音频数据，适合作为当前配置留档。

## 规划与落实核对

| 规划需要 | 已接入内容 | 保留的边界 |
| --- | --- | --- |
| 从首页到学习、奖励、商店、花园和家长设置都有可识别反馈 | 30 个交互使用点，通用点击覆盖没有专属反馈的按钮，重点动作使用独立事件 | 语音和麦克风优先；禁用按钮、录音启动等场景不会为了点击反馈强行发声 |
| 通过声匣逐项挑选适合纸艺花园的素材 | 17 段 CC0 短音效已放入静态资源目录，并保留来源与哈希 | 已完成候选比较、解码、时长和音量检测；未进行人工听感验收，不能将客观检测称为实际试听 |
| 页面有轻柔背景音乐 | 只在自由花园播放原有钢琴，正常进出淡入淡出 | 本轮未从声匣取得新的长 BGM；原曲沿用项目原有来源记录，不标为 CC0。学习页面没有 BGM |
| 所有声音在 GM 中可查、可调 | 31 个使用点可筛选、试听、禁用、解绑、替换、上传、恢复、导出 | 浏览器本地配置；新增触发事件和把配置发布为所有用户的默认值需改动项目 |
| 静态发布和离线可用 | 17 个文件进入构建音频清单，随包复制并进行哈希校验；支持离线音频范围请求 | 首次需下载并缓存对应资源；离线可用不等于首次无网络也能取得未缓存文件 |
