## v0.2 · 聚焦首次体验（2026-10-16）

用户首轮反馈：主题同时出现使孩子不知道从哪里开始，中文机械、缺少明确操作引导。本轮首页改为单一主入口，连续教会听、挥手、录音、回听、领奖和摆放；步骤内只突出一个主操作，等待真实音频结束后才开放。首次不弹录音选择、不准备识别资源；录音由孩子点话筒后才请家长协助。三次不同事件完成后再出现主题选择。

`preferences:v1` 增加可续接的 `guideStep`，已有学习记录不迁移或清空。录音仍仅在内存，刷新后的回听步骤恢复到重新说话，并先复播英文。引导中没有测验性质的选择题，不记录听辨或口语能力证据；领奖与摆放分别保存，可在保存失败后重试而不重复发奖。退出、后台或跨标签更新会取消声音与录音；拒麦、无录音能力或暂时不想说可先听示范继续。

中文更换为预制的神经语音；增加明确指向耳朵、话筒、图画和领奖的提示，普通事件也增加下一步动作提示。录音完成后中央主操作切换为回听自己的大耳朵，同时收起英文示范入口，避免语音与按钮指向不一致。英文 Pip 资源不变，中文 URL 与声音缓存升级 v2。新美术为轻量 SVG 与 CSS 动画，没有增加图片模型或首屏下载包。
