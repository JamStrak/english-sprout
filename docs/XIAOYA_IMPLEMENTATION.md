# 小芽英语 · 实施记录

## v0.2 · 聚焦首次体验（2026-10-16）

用户首轮反馈：主题同时出现使孩子不知道从哪里开始，中文机械、缺少明确操作引导。本轮首页改为单一主入口，连续教会听、挥手、录音、回听、领奖和摆放；步骤内只突出一个主操作，等待真实音频结束后才开放。首次不弹录音选择、不准备识别资源；录音由孩子点话筒后才请家长协助。三次不同事件完成后再出现主题选择。

`preferences:v1` 增加可续接的 `guideStep`，已有学习记录不迁移或清空。录音仍仅在内存，刷新后的回听步骤恢复到重新说话，并先复播英文。引导中没有测验性质的选择题，不记录听辨或口语能力证据；领奖与摆放分别保存，可在保存失败后重试而不重复发奖。退出、后台或跨标签更新会取消声音与录音；拒麦、无录音能力或暂时不想说可先听示范继续。

中文更换为预制的神经语音；增加明确指向耳朵、话筒、图画和领奖的提示，普通事件也增加下一步动作提示。录音完成后中央主操作切换为回听自己的大耳朵，同时收起英文示范入口，避免语音与按钮指向不一致。英文 Pip 资源不变，中文 URL 与声音缓存升级 v2。新美术为轻量 SVG 与 CSS 动画，没有增加图片模型或首屏下载包。

本轮构建 `0.2.0 · 976cd950ec41`，旧产品构建仍为 `c4bccf69eebc`。核心壳共 182,631 字节，56 条中文音频共 1,841,872 字节，按需下载。20 条引导和操作提示使用本地 Qwen Serena，36 条生活情境提示使用制作期预制的 XiaoxiaoNeural；运行时均播放静态文件。声音清单逐条记录来源、文案和哈希，全部通过解码与信号检查；36 条情境的返回逐词文本覆盖完整文案。没有新增运行时语音服务。

`npm test` 260 项通过，`npm run build` 通过；56 条构建音频与来源文件哈希一致。旧产品浏览器回归 36 项通过，报告见 `docs/UI_QA_xiaoya-v02-old-regression.md`。最终构建的新版浏览器检查 38 项全部通过：首次引导 13 项、主流程 16 项、竞态 3 项、完整本地识别链路 6 项；覆盖录音后唯一主操作为回听、中文 v2 离线缓存、旧存档保留、小屏布局和异常退出。报告位于 `test-results/xiaoya-onboarding/`、`test-results/xiaoya-v01/`、`test-results/xiaoya-races/`、`test-results/xiaoya-speech/`。识别检查使用已知语音输入，不代表真实儿童识别准确率；人工听感、真实孩子对引导的理解仍需试玩反馈。

首版 `0.1.0`，新产品构建 `e5037253d61c`。旧产品构建仍为 `c4bccf69eebc`。使用说明见 [XIAOYA_USE.md](XIAOYA_USE.md)。

- 六主题、18 个生活事件、36 个具体情境、18 件固定家具；无英文字母主线包含听声音找图、开口邀请、示范帮助和布置小屋。
- 复用 16 条 Pip 英文配音，新增 43 条本机合成中文帮助；新增音频约 2.05 MB，核心壳资源约 160 KB，声音按需缓存。约 47 MB 的本地识别资源仅在家长明确准备后下载。
- 真正的临时录音与回听，停顿结束或最长 12 秒，退出、转入后台、跨标签记录替换时释放麦克风。录音、转写不持久化或上传。
- 听懂、提示下表达、独立表达、隔天换情境表达分别记录；家长观察可更正且保留原始记录。选择题、机器匹配与家具都不能冒充口语掌握。长期参与缺少观察、连续观察仍无独立表达会提示家长跟进。
- 家长门控后的 26 个发现活动，需要表达证据才能收集；集齐后，某句仍需自己的跨日、跨情境完整原句证据，才显示拼写。首版无字母教学进度对口语能力的反向加分。
- 独立双击启动器、离线壳与声音缓存、存档导出和损坏记录保护。首版尚无新版存档导入或跨设备同步。

真实识别专项最终两次录音均为 22,925 字节、解码时长 5.04 秒，原始识别结果均为 `good morning`；离线冷重开没有重新请求模型。最终构建对应上述新版浏览器、竞态与识别三套报告。浏览器自动化中的模拟麦克风不代表实体设备录音或儿童发音识别准确率；首版门槛为待试玩调整的产品规则。

测试时序修正：三套浏览器同时录音时，迟到结果专项曾在识别启动前超时；固定等待 2.8 秒没有保证假麦已输出足够采样，改为被动观察实际有效声音后停麦。该修正没有改变产品的声音门槛，也没有放宽取消和奖励断言。真实识别专项也曾出现一次未匹配；早期失败没有保留原始录音，不能事后认定具体原因。最终测试在原生录音启动后才输入完整已配音频，并持续提供真实静音采样供产品自动结束，消除了音源启动的固定延时假设；完整 6 项独立运行通过，产品识别与计时规则未因此修改。合成音源试验中一度缺少播完后的静音采样，已修正测试夹具。

## 首轮试玩关注

优先观察孩子能否理解场景、是否愿意开口、中文帮助能否解除困惑、家长是否能分清有提示和独立表达。随后用隔天换场景的回访判断是否保留所学，避免仅凭当天顺利跟读推进。

本轮交付范围为本机可试玩版本，未发布外网；手机和平板真机试玩需后续 HTTPS 入口。视觉、语音节奏和示范用语仍可随真实试玩反馈迭代。
