# 小芽花园冒险：游戏呈现层

目标：让孩子在同一个花园世界里找到一个清楚的下一步。首页是出发点，复习是「唤醒老朋友」，新句是「收集新发现」，阶段小测是「记忆寻宝」，学习带回的种子和水壶用于自由种花。朋友不会因漏学受伤，花朵不会枯萎，已获得的身份不会因中断练习降级。

## 规则归属

`src/adventure.js` 只有纯派生函数 `getAdventure(state, lessons, today)`。传入已验证的学习状态与课程；不会保存新字段、发资源或改变任何学习记录。

- 当前任务直接来自 `getTodayJourney`。复习优先、每日新增额度、记忆小游戏的日期和候选仍由 `src/learning.js` 决定；新标题不能绕过限额。
- 种子、水壶、植物、旧版迁移与成长次数仍来自 `getGarden`。最近目标只提示真实可做的事，不是第二份奖励账本。
- 首次目标是发现一句并播种；已种植物选择距离开花最近的一株作为小目标。没有水时引导跟读获取现有的每轮 2 水奖励。随机种子明确写「有机会」，不承诺每轮获得。
- 花园已满且全部成熟时，目标转为欣赏花海，不强迫增加学习或制造不可完成的播种任务。

## 成长身份

称号是园丁旅程的纪念，**不是英语等级或掌握证明**。每个唯一新句的学习记录与每朵真实开出的花各贡献 1 次成长足迹；重复跟读、普通浇水、刷新页面不会直接提高称号。阶段门槛为 0、3、10、25、60、150、400、1000，依次对应小芽探险家、种子伙伴、花园小帮手、花朵好朋友、彩虹园丁、花海探险家、星光园丁、花园梦想家。

旧版已经收获的植物保留贡献；仍在旧花盆中、尚未收获的成熟植物也计入一次，后来收获不会重复增加。旧植物原有的 3 或 12 次成长目标保留。

## 界面集成契约

返回对象大小不随花园植物数量增长，所有值可 JSON 序列化：

| 字段 | 含义 |
| --- | --- |
| `rank.level/title/icon` | 当前园丁称号及图标 |
| `rank.current` | 累计成长足迹，新句与真实开花之和 |
| `rank.target/nextTitle` | 下个称号的累计门槛与名称，最高级为 `null` |
| `rank.progress` | **当前称号区间**的 0–1 进度，最高级为 1；不是 `current / target` |
| `quest.kind/title/hint/button/symbol` | 与现有学习顺序一致的当前任务与短文案 |
| `quest.count/lessonId/nextKind` | 当前任务数量、首句与下一类任务；无课程为 `null` |
| `stats.learnedCount/bloomCount/plantCount/practiceDays/seeds/water` | 真实累计发现、开花、当前植物、原学习练习日及库存 |
| `nextGoal.kind/title/hint/current/target/remaining/progress` | 一个可达的小目标；`progress` 为 0–1，完成花海为 1 |

每次成功保存学习或种植操作后重新调用，不将上次模型当作状态保存。页面可用 `quest.kind` 复用已有开始流程，用 `rank` 和 `stats` 打开冒险手册。低龄儿童的首页只显示当前任务；细节计数放手册，不用等级数字遮住核心图像与动作。

本机跟读目前是词句匹配，不是专业发音评分；找图判断是理解证据，不是发音准确率或完全掌握。园丁称号不改变这一区分。

## 验证范围

`tests/adventure.test.js` 覆盖新用户、复习优先、每日额度与复习积压、记忆小游戏日期、真实开花贡献、不中断掉级、旧花园兼容、资源不增发、1600 株的有界输出、冻结输入和重复读取。不把纯模型单测称为儿童可玩性或真人发音验收。

## v1.8.0 实际界面与验收

- 首页在生图世界中展示当前任务插图、个人动物角色、真实背包数字。整块画面和主按钮均能出发。复习、新句、记忆小游戏按原学习规则分配。
- 练习有图标路线和当前步骤；大麦克风与图片配对保留实际自动词句匹配、理解证据及温和重试。路线表示正在走到哪个环节，不声称仅经过听图环节就已听懂。
- 得到浇水奖励时，先原子保存学习记录与资源，再自动展示单操作水壶弹窗；整块水壶按钮可点，背景、Escape、Tab 均不能绕过领取。点击只确认展示并继续，不再次发奖。刷新或关页后奖励仍在背包，导航/跨标签更新会废弃旧弹窗回调。资源数字取这一次事务前后的 earned 差值，包含当天学习/复习与跟读带来的水、种子、肥料，不能把全部奖励固定写成 +2。
- 新学和已学句子的自由跟读在匹配后自动弹奖；复习仍先完成听音找图，记忆小游戏仍整轮保存后弹奖。未知句子自由试听不发奖；保存失败不显示虚假到账，保留存储处理入口。不用评分的练习先由孩子明确确认练过，不能自动假称口语通过。
- 领取后继续原来的下一题、完成页或花园；完成页显示本轮补给和下一项任务。弹窗沿用 showDialog 兼容 iPadOS 15.1，动效遵循减少动态设置，不新增网络音效或录音持久化。
- 花园自由播种和浇水，选中植物显示真实成长目标；装饰小路、池塘和草丛不占用种植坐标。无种子时先引导学习，已有苗而无水时引导跟读。地图、工具和任务入口始终可见。
- 冒险手册显示园丁称号和累计发现/开花/练习日；跨门槛在既有完成页或开花提示直接庆祝，不另开强制弹窗。
- 大花园记录派生结果按学习状态对象和本地日期缓存；保存（含设置变更）使缓存失效。`getAdventure`可接受当前日期已算好的第四参数`preparedGarden`，避免同一界面重复重放账本。
- 场景原画使用内置image_gen制作，正式WebP约249KiB，纳入离线核心；[实际提示词与资源](../design/adventure-world/README.md)。没有增加运行时图片/语音生成API。
