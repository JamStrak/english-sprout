# 练习与复习规则

版本：状态格式 v1；实现：`src/learning.js`。本说明对应自动测试覆盖的规则，不代表对儿童学习效果进行了临床或长期实测。

## 每天怎么安排

- 每天最多学一个没学过的新句，按课程目录顺序选择。中断几天后继续下一句，不跳课、不补欠课、不扣奖励。
- 每天默认复习 5 句，设置支持 1–10 句。先安排到期最早的句子，同一天到期按课程顺序。
- 未轮到的到期句留待后面，不要求今天全部清空。每天已经完成的复习占用当天名额；重新打开应用不会重置名额。
- 课程预览、播放示范音和浏览句库不会自动建立学习记录。练习流程结束后才记录自我/家长反馈。
- 同一句同一天只保存第一次最终反馈；连续点击、再听再说不会反复增加间隔。允许继续练习，但不会制造多次有效回忆的数据。

这里没有单独存储一份全天计划快照。稳定性来自“按原到期日排序 + 剩余名额 = 每日上限减去已经完成数”。当日正常完成一条后，其余待办顺序保持不变。修改每日复习数量会明确改变当天剩余名额。两个设备的进度不会自动同步；导入备份是明确替换本设备进度。

## 间隔与反馈

首次接触无论反馈如何，都算“今天接触过这句”，第二天再见。新句完成不等于已经记住。

此后连续选择“会说了 / good”，复习间隔依次为 3、7、14、30、60、90 天，再保持 90 天。因此完整起点为 **1、3、7、14、30、60、90 天**。

- `good`：复习阶段加一，按对应间隔安排。
- `help`：阶段降低一级（最低 0），明天再练。
- `again`：回到第 0 阶段，明天再练。首次学习的 `again` 不算遗忘次数。
- 晚了几天才复习：从实际练习当天计算下一次日期，不连续追加补练。

这是透明、可调整的间隔复习安排，并非针对个体测得的“记忆曲线”，也不是能保证记牢的算法。反馈来自孩子/家长观察，不是自动发音评分；不同日期能否在真实情境使用才是更有价值的证据。“熟悉”只是阶段达到 3 的内部进度标签，不叫“掌握率”。

## 记忆小游戏

首次使用满 7 天后出现，完成一次后至少间隔 7 天；错过不累计欠测。每次最多 3 句，从至少 3 天前接触过且当天尚未常规练习的句子中选取，优先最久未测与到期较早的句子。课程不足时允许 1–2 题。

每题先看配图尝试说，家长选「再练 / 提示后会说 / 自己会说」。揭晓过示范后不能再选「自己会说」。随后听音选图，记录第一次是否听懂；答错可继续尝试，不扣奖励。整轮完成才保存；中途离开不计完成、不发小测奖励。

小测的听辨和表达观察分开保存，不能把选对图片视为发音准确。小测不提高复习阶段或延长间隔；听辨错误或需要表达提示的句子，次日提前进入普通复习队列。即使全部选对，也只表示这次观察顺利，不显示“完全掌握”。

## 轻量收集花园

奖励直接从学习历史计算：新学一句得到 1 颗种子；有练习的一天得到 2 滴水（包括仅完成小测）；当天做过普通复习再加 1 滴水。完整小测再得 1 颗种子和 1 份肥料。累计接触 5、10、20、40、80、120 句时各奖励 2 颗种子、1 份肥料，每个里程碑只给一次。奖励不依赖“会说”评分，诚实反馈同样得到奖励。

三块地每次播种用 1 颗种子，自动优先安排尚未收集和未在种的植物。浇水用 1 滴水、施肥用 1 份肥料，各长一格；三格成熟后可收获，加入向日葵、郁金香、草莓或蓝铃花图鉴。每块地每天最多浇水一次、施肥一次，收获重种也不会重置当日次数。界面只显示当下一个主动作，没有商店、装备或任务树。漏学不会枯萎，不收回奖励。

操作保存为日期与顺序明确的 `garden.actions`；导入会重放资源收入和支出，拒绝资源不足、提前收获等不可能记录。旧记录保留既有学习历史，并据此获得对应种子、水滴与里程碑奖励。

## 日期、隐私与备份

当天日期取设备的本地年月日；日期加减在日历组件上计算，避免 UTC 跨日和夏令时把复习挪一天。设备日期调回已记录日期之前会拒绝冲突写入，提示检查日期。

记录包含昵称、每日复习量、已学课程的到期日期及逐日最终反馈。备份中不包含麦克风录音、音频或账户身份。导入严格检查格式、课程编号、真实日期、每日重复结果、次数与完整历史的一致性；未知字段、原型污染键、未来不兼容格式和过大 JSON 会拒绝，不把外部 JSON 当作代码执行。

`getDailyPlan` 返回剩余复习编号和额外到期数量；`reviewDone` 是数量、`newDone` 是布尔值，`newLessonId` 在当日完成后仍保留当天新句编号。`getStats` 的 learnedCount / totalLearned 只表示接触过的句子数量。

状态仍为 v1，新增可选 `checkups` 和 `garden`，缺少这两项的旧备份自动按空记录读取。新备份同时携带小测和花园，音色偏好作为设备设置另存，不随学习备份迁移。

## 验证入口

执行 `node --test tests/learning.test.js tests/checkup.test.js tests/garden.test.js`。测试覆盖本地午夜、闰年、跨月、间隔推进、卡住后退、同日防重复、断更恢复、每日上限、反复载入、导入边界和两年模拟练习。自动测试可验证规则实现，不能替代真实儿童体验和长期学习结果观察。
