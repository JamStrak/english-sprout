# 练习与复习规则

版本：状态格式 v1；实现：`src/learning.js`。本说明对应自动测试覆盖的规则，不代表对儿童学习效果进行了临床或长期实测。

## 每天怎么安排

- 通常每天最多新增 3 句，完成后显眼显示“再学一句”，按课程目录顺序选择。有未完成的到期复习时，新增上限为 1；当天开始到期积压达到 10 句，完成部分复习后上限仍为 1。这是产品的学习负荷规则，不是医学健康阈值。达到上限可去短句广场自由听说，不新增复习任务。中断几天后继续下一句，不跳课、不补欠课、不扣奖励。
- 每天默认复习 5 句，设置支持 1–10 句。先安排到期最早的句子，同一天到期按课程顺序。
- 未轮到的到期句留待后面，不要求今天全部清空。每天已经完成的复习占用当天名额；重新打开应用不会重置名额。
- 课程预览、播放示范音和浏览句库不会自动建立学习记录。完成流程后才记录本机词句匹配和首次听音找图结果；识别未完成可自主开口继续，不记自动通过。
- 同一句同一天只保存第一次最终反馈；连续点击、再听再说不会反复增加间隔。允许继续练习，但不会制造多次有效回忆的数据。

这里没有单独存储一份全天计划快照。稳定性来自“按原到期日排序 + 剩余名额 = 每日上限减去已经完成数”。当日正常完成一条后，其余待办顺序保持不变。修改每日复习数量会明确改变当天剩余名额。两个设备的进度不会自动同步；导入备份是明确替换本设备进度。

## 间隔与反馈

首次接触无论反馈如何，都算“今天接触过这句”，第二天再见。新句完成不等于已经记住。

此后独立回想的本机词句匹配通过、首次听音找图正确，记录 good，复习间隔依次为 3、7、14、30、60、90 天，再保持 90 天。因此完整起点为 **1、3、7、14、30、60、90 天**。

- `good`：复习阶段加一，按对应间隔安排。
- `help`：阶段降低一级（最低 0），明天再练。
- `again`：回到第 0 阶段，明天再练。首次学习的 `again` 不算遗忘次数。
- 晚了几天才复习：从实际练习当天计算下一次日期，不连续追加补练。

这是透明、可调整的间隔复习安排，并非针对个体测得的“记忆曲线”，也不是能保证记牢的算法。自动反馈来自词句匹配与听音配图，不是专业发音评分；不同日期能否在真实情境使用才是更有价值的证据。“熟悉”只是阶段达到 3 的内部进度标签，不叫“掌握率”。

## 记忆小游戏

首次使用满 7 天后出现，完成一次后至少间隔 7 天；错过不累计欠测。每次最多 3 句，从至少 3 天前接触过且当天尚未常规练习的句子中选取，优先最久未测与到期较早的句子。课程不足时允许 1–2 题。

每题先看配图尝试说，本机识别自动匹配词句；使用示范提示后记 help，不算独立回忆。随后听音选图，记录第一次是否听懂；答错可继续尝试，不扣奖励。整轮完成才保存；中途离开不计完成、不发小测奖励。

小测的听辨和词句回想分开保存，不能把选对图片视为发音准确。小测不提高复习阶段或延长间隔；听辨错误或需要表达提示的句子，次日提前进入普通复习队列。即使全部选对，也只表示这次观察顺利，不显示“完全掌握”。

## 多次练习与大花园（v1.7.0）

每日基础奖励保持：新学一句得到 1 颗种子；有练习的一天得到 2 次浇水（包括仅完成小测）；当天做过普通复习再加 1 次。完整小测再得 1 颗种子和 1 份营养。累计接触 5、10、20、40、80、120 句时各奖励 2 颗种子、1 份营养。诚实选择“还要练练”仍得到基础奖励。

正常学习和复习的开口步骤直接显示“跟读评星”；复习必须接着听音选图，答错的句子记 again、次日再练；未获得自动匹配时手动继续最多记 help，不会自己点出 good。额外花园跟读也有独立轮次：从已经接触的课程里选一句，听后录音，本机识别英文词句并比较顺序，匹配通过显示三颗跟读星星，每轮获得 2 次浇水。星星表示词句匹配，不是音素、口音、发音准确率或完全掌握。识别不清、麦克风不可用、模型下载失败时，孩子可自行照图开口后领取明确标注的鼓励水，不依赖家长在场，也不伪造自动通过。新版本完整轮次有约三分之一机会另得一颗种子，按轮次 ID 固定生成、刷新不重抽；旧版历史的每三轮奖励保持；自由听书和播放示范不自动发奖励。

大花园采用 3000×3000 画布，允许自由位置播种，最多 1600 株。种子、水壶可拖放，或点选工具再点落点；拖空地移动视野，＋/−放缩、地图看全景、小苗按钮回到植物。新苗每次浇水长一格，5次开花，按进度缩放并换形态；四种花型、六种外观变化，成熟自动加入收藏且留在花园。没有枯萎惩罚。画布渲染避免上千个页面节点，资源保存成功才庆祝。

学习状态仍为 v1：newId/newDone 保留首句兼容语义，多句记录在 results，理解证据是可选 meaning 布尔值。花园账本 v3：legacyCount 保留最早每日限制前缀，classicCount 保留所有旧奖励前缀；旧三格/十二格苗、收藏和余额不重置。新动作记录植物 ID、位置和唯一浇水 ID，备份按完整历史重放，拒绝超额消费、重叠播种和重复奖励。只记录词句匹配评价方式，不保存录音或识别文本。

额外跟读不写 cards/days/checkups，不提高复习阶段、延长日期或制造口语掌握记录；同一句同一天的普通学习反馈仍只保存第一次。自动识别模型为 Vosk small English 0.15，首次进入跟读按需下载模型约 41 MB、识别脚本约 6 MB；模型与脚本支持后台分段续传，完整压缩包在独立缓存，解压模型在 IndexedDB，首屏与核心离线安装不等待它；准备未完成时本次评测最多等待15秒，孩子可继续领鼓励水，后台保留下载进度。下载后可本机离线匹配；录音及临时文本不上传。真实儿童口音与实体 iPadOS 15.1 性能尚未验收，识别失败并不表示孩子发音不好。

## 日期、隐私与备份

当天日期取设备的本地年月日；日期加减在日历组件上计算，避免 UTC 跨日和夏令时把复习挪一天。设备日期调回已记录日期之前会拒绝冲突写入，提示检查日期。

记录包含昵称、每日复习量、已学课程的到期日期及逐日最终反馈。备份中不包含麦克风录音、音频或账户身份。导入严格检查格式、课程编号、真实日期、每日重复结果、次数与完整历史的一致性；未知字段、原型污染键、未来不兼容格式和过大 JSON 会拒绝，不把外部 JSON 当作代码执行。

`getDailyPlan` 返回剩余复习编号、额外到期数量及 nextNewLessonId/canLearnMore/newCount/newLimit/limitReason；`reviewDone` 是数量、`newDone` 是布尔值，`newLessonId` 在当日完成后仍保留当天新句编号。`getStats` 的 learnedCount / totalLearned 只表示接触过的句子数量。

学习状态仍为 v1，新增可选 `checkups` 和 `garden`（支持花园账本 v1/v2/v3），缺少这两项的旧备份自动按空记录读取。新备份同时携带小测和花园，音色偏好作为设备设置另存，不随学习备份迁移。

## 验证入口

执行 `node --test tests/learning.test.js tests/checkup.test.js tests/garden.test.js`。测试覆盖本地午夜、闰年、跨月、间隔推进、卡住后退、同日防重复、断更恢复、每日上限、反复载入、导入边界和两年模拟练习。自动测试可验证规则实现，不能替代真实儿童体验和长期学习结果观察。
